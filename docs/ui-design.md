# 曝光参谋 · UI 设计规格 v0.1

修订记录：v0.1 — 2026-10-26 首版定稿，为 v1.0 二期界面施工依据。

配套样张：`ui-design-board.html`（6 个手机界面样张 + 红光对照）。样张数值为示意（取自设计文档算例），非真实历算结果。

## 1. 设计定调

- **仪器感**：深空黑底、低饱和、高信息密度、层级清楚；像天文器材的控制面板，不做消费 App 的圆润花哨风。
- **夜间优先**：一切设计先过「黑暗环境」这一关——对比度靠亮度层级而非彩色，强调色克制使用，红光模式为整套独立主题而非滤镜。
- **结论先行**：任何界面第一眼必须看到结论（今晚能不能拍、拍多久），输入与细节在后。

## 2. 设计令牌（Design Tokens）

### 深色主题（默认）
| 角色 | 值 | 用途 |
|---|---|---|
| bg | #05070D | 页面底 |
| surface | #0C1120 | 卡片 |
| surface2 | #131B31 | 卡片内嵌 / 输入区 |
| border | #22304F | 卡片描边 1px |
| text | #E9EEF8 | 主文字 |
| text2 | #96A3BE | 次文字 / 理由 |
| text3 | #5D6C8C | 弱文字 / 注脚 |
| accent | #F2C66D | 星光金：主结论、关键数值 |
| info | #6EA8FE | 链接 / 信息态 |
| ok | #4CC38A | 条件良好 |
| warn | #F5A524 | 提醒 / 降级 |
| bad | #E5484D | 不适合 / 安全警告 |

### 红光主题（全局替换，护暗适应）
只用红光谱：bg #0A0202、surface #180404、surface2 #220707、border #471512、text #FF7A6B、text2 #D64A3E、text3 #8F2B21、accent #FF9D8A。禁止出现蓝 / 绿 / 白；照片类元素（如示意缩略图）在红光下以红阶呈现。

红光状态色（与深色主题的 info / ok / warn / bad 一一对应，全部取红光谱，靠亮度拉开层级）：info #FF9D8A（与 accent 同值）、ok #E5563C、warn #FF7A45、bad #FF4A3D。红光下状态**不单独依赖色相传达信息**：一律「亮度 + 图标 + 线型」三重编码——ok 配 ✓ 图标与实线边框，warn 配 ! 图标与虚线边框，bad 配 ▲ 图标与粗实线顶栏，info 以描边与正文区分。此口径与功能设计「全部界面红光呈现、不依赖红以外的颜色传达信息」一致。

### 字体与度量
- 数值用等宽数字（tabular），结论数值 ≥ 34sp，其余正文 14–16sp，注脚 ≥ 12sp。
- 圆角：卡片 16dp、控件 12dp；卡片内边距 16dp；卡片间距 12dp。
- 触控目标 ≥ 48dp（戴手套操作）；主要操作单手拇指区可达。

## 3. 信息架构

底部四栏：**今晚 / 计算 / 计划 / 设置**。

- 今晚（首页）：天象概览卡（暮光、月相、银心窗口）→ 今晚推荐（简化版榜单）→ 五类入口。
- 计算：五类目标的计算器列表 → 输入页 → 结果卡片页。
- 计划：已保存计划（卡片列表）+ 导出 / 导入。
- 设置：设备库（相机 / 镜头 / 跟踪档案）、地点收藏、严苛档默认值、红光模式（含日落后自动）、语言、时间健康状态。

## 4. 关键界面

1. **今晚概览**：顶部状态行（地点 + 日期 + 时间健康绿点）；天象卡（日落 / 天文暮光 / 银心窗口 / 月相四格）；「今晚推荐」榜单行（目标名 + 类别 + 推荐理由一句话 + 最佳时段）；五类入口宫格。
2. **参数卡片（结果）**：卡顶 = 类别 + 严苛档徽章；主体 = 2–4 个大数值（快门 / 光圈 / ISO / 张数）；下方理由列表（每条一句人话，含所用赤纬、图谱角标等）；降级时卡顶整条变 warn 色并直言原因；底部操作：保存计划 / 微调重算。
3. **计算器输入**：分组输入——设备（相机 / 镜头选择器）、场景（目标类别相关项）、档位（严苛三档分段控件 + 系统推荐标注）；数值项用大步进器与滑杆组合，禁止小下拉框；底部固定「计算」主按钮。**光圈为专用控件（2026-10-26 决定）**：不用自由数值填写，改为标准档位选择器——档位序列取相机通用的 1/3 档名义刻度（1.4 / 1.6 / 1.8 / 2.0 / 2.2 / 2.5 / 2.8 / 3.2 / 3.5 / 4.0 / 4.5 / 5.0 / 5.6 / 6.3 / 7.1 / 8 / 9 / 10 / 11 / 13 / 14 / 16 / 18 / 20 / 22；镜头最大光圈小于 f/1.4 时把 1.0 / 1.1 / 1.2 纳入），起点为所选镜头的最大光圈（默认停在最大光圈），终点 f/22；交互为左右步进按钮 + 可横滑的刻度带，吸附到最近档位，不出现相机上不存在的数值。焦距为连续量，保持数值 + 滑杆，不套档位。
4. **时刻列表**：纵向时间线（时刻 + 事件名 + 一句说明），当前时段高亮，低月光窗口用 ok 色带标注；v1.0 为列表形态，图形时间轴 v1.1。
5. **红光模式**：与深色主题同一布局整套换红阶；开关在设置与首页状态行各一处（一键切换），可选日落后自动开启。

## 5. 状态呈现（与功能设计一一对应，不许粉饰）

- **跟踪档案未实测**：跟踪卡片不给秒数，显示换算公式 + 「待基线实测录入」徽章（warn）。
- **满月降级**：深空 / 银河卡片顶部直言提示条（bad→warn 口径，写死文案模板）。
- **天光为图谱估算**：角标小字，不算降级；手动 Bortle 覆盖后角标变「手动覆盖」。
- **日食安全闸门**：不可跳过的全屏提醒样式（bad 色顶栏 + 确认勾选后才显示参数）。
- **时间健康异常**：首页状态行红点 + 一行说明（时区不一致 / 时钟偏差）。

## 6. 交互规则

- 所有计算页遵循同一流：输入 → 大按钮计算 → 结果卡（结论 + 理由）→ 可保存为计划。
- 改任一输入后结果不自动乱跳，点「重算」或防抖 300ms 后刷新并标注已更新。
- 档位切换即时重算并在卡上更新档徽章。
- 返回保留输入；计划卡可一键复用当晚重算。
