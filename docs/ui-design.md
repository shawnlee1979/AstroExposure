## 1. 设计定调

- **仪器感**：深空黑底、低饱和、高信息密度、层级清楚；像天文器材的控制面板，不做消费 App 的圆润花哨风。
- **夜间优先**：一切设计先过「黑暗环境」这一关——对比度靠亮度层级而非彩色，强调色克制使用，红光模式为整套独立主题而非滤镜。
- **结论先行**：任何界面第一眼必须看到结论（今晚能不能拍、拍多久），输入与细节在后。

### 字体与度量
- 数值用等宽数字（tabular），结论数值 ≥ 34sp，其余正文 14–16sp，注脚 ≥ 12sp。
- 圆角：卡片 16dp、控件 12dp；卡片内边距 16dp；卡片间距 12dp。
- 触控目标 ≥ 48dp（戴手套操作）；主要操作单手拇指区可达。

## 3. 信息架构

底部四栏：**今晚 / 计算 / 计划 / 设置**。

- 今晚（首页）：地点卡 → 日期切换 → 时间轴（页面主干，整合曲线、区间、时刻标记与推荐联动，规格见第 7 节）→ 事件小节 → 五类入口。
- 计算：五类目标的计算器列表 → 输入页 → 结果卡片页。
- 计划：已保存计划（卡片列表）+ 导出 / 导入。
- 设置：设备库（相机 / 镜头 / 跟踪档案）、地点收藏、严苛档默认值、红光模式（含日落后自动）、语言、时间健康状态。

## 4. 关键界面

1. **今晚页**：地点卡（定位 + 光害同卡）→ 日期切换行 → 时间轴主干 → 推荐区 → 事件小节 → 五类入口宫格；顶部另有时间健康状态。完整规格见第 7 节。
2. **参数卡片（结果）**：卡顶 = 类别 + 严苛档徽章；主体 = 2–4 个大数值（快门 / 光圈 / ISO / 张数）；下方理由列表（每条一句人话，含所用赤纬、图谱角标等）；降级时卡顶整条变 warn 色并直言原因；底部操作：保存计划 / 微调重算。
3. **计算器输入**：分组输入——设备（先选相机、再选镜头）、场景（目标类别相关项）、档位（严苛三档分段控件 + 系统推荐标注）；数值项用大步进器与滑杆组合，禁止小下拉框；底部固定「计算」主按钮。**镜头从镜头库选择，不自由填写焦距（2026-10-26 起执行）**：镜头库 = 内置五家清单 + 用户自定义（含定焦与变焦）；选中后焦距与最大光圈由镜头数据带出。定焦无焦距控件；变焦在该镜头焦段内用滑杆 / 步进选焦距（连续量，保留数值呈现）。想用的镜头不在库里时，入口引导先去设置页镜头库添加自定义镜头，计算器内不设临时填写。光圈选择器的起点随所选镜头联动：变光圈变焦按当前焦段的有效最大光圈（镜头数据支持时），数据只有单一最大光圈时用该值。**光圈为专用控件（2026-10-26 起执行）**：不用自由数值填写，改为标准档位选择器——档位序列取相机通用的 1/3 档名义刻度（1.0 / 1.1 / 1.2 / 1.4 / 1.6 / 1.8 / 2.0 / 2.2 / 2.5 / 2.8 / 3.2 / 3.5 / 4.0 / 4.5 / 5.0 / 5.6 / 6.3 / 7.1 / 8 / 9 / 10 / 11 / 13 / 14 / 16 / 18 / 20 / 22），序列起点为镜头最大光圈（默认停在最大光圈）：比最大光圈更大的档位不出现，如 f/1.2 镜头自 1.2 起、f/1.4 镜头自 1.4 起，终点 f/22；交互为左右步进按钮 + 可横滑的刻度带，吸附到最近档位，不出现相机上不存在的数值。焦距为连续量，保持数值 + 滑杆，不套档位。
4. **关键时刻呈现**：九类关键时刻全部落为时间轴上的标记（见 7.4），点按标记弹出该时刻详情；原页尾纵向时刻列表取消。低月光窗口与银心可见窗口画为轴上区间带（见 7.4）。
5. **红光模式**：与深色主题同一布局整套换红阶；开关在设置与首页状态行各一处（一键切换），可选日落后自动开启。

## 5. 状态呈现（与功能设计一一对应，不许粉饰）

- **跟踪档案未实测**：跟踪卡片不给秒数，显示换算公式 + 「待基线实测录入」徽章（warn）。
- **满月降级**：深空 / 银河卡片顶部直言提示条（bad→warn 口径，写死文案模板）。
- **天光为图谱估算**：角标小字，不算降级；手动 Bortle 覆盖后角标变「手动覆盖」。
- **日食安全闸门**：不可跳过的全屏提醒样式（bad 色顶栏 + 确认勾选后才显示参数）。
- **时间健康异常**：首页状态行红点 + 一行说明（时区不一致 / 时钟偏差）。显示时区与设备时区不一致时，今晚页另以一行小字标注当前显示时区名（口径见 7.6）。
- **地点卡无光害网格数据**：地点卡内明示「暂无网格数据」，并就地给出手动 Bortle 选择（口径见 7.2），不留空、不凑数。

## 6. 交互规则

- 所有计算页遵循同一流：输入 → 大按钮计算 → 结果卡（结论 + 理由）→ 可保存为计划。
- 改任一输入后结果不自动乱跳，点「重算」或防抖 300ms 后刷新并标注已更新。
- 档位切换即时重算并在卡上更新档徽章。
- 返回保留输入；计划卡可一键复用当晚重算。

## 7. 今晚页时间轴整合规格

今晚页以一根时间轴为页面主干：地点卡、日期切换、静态四层时间轴、游标联动推荐与事件小节按本节口径实现。分期与版本见 7.7。

### 7.1 通则：手机框内只出现产品文案

- 界面与样张的手机框内，只出现真实 App 会有的产品文案：短、直接、面向使用者。
- 设计解说一律放在手机框外的面板或本文档中，框内不混入解说腔（包括「点数字可直接改」这类对设计意图的提醒文字）。
- 本通则适用于全部界面与全部样张。

### 7.2 地点卡

定位与光害合并为一张卡，置于今晚页顶部：

- **定位行**：进入今晚页默认自动 GPS 定位。经纬度以数字文本呈现，数字后跟一个小编辑图标 ✎ 示意可编辑，点按数字原地进入编辑、确认即生效；卡内不设独立的手动输入块，也不出现提醒类文案。编辑校验：纬度 −90°…90°、经度 −180°…180°，越界输入不生效并就地提示。编辑后来源标记为「手动」；再次点按定位按钮即以新的 GPS 结果覆盖，不另设确认步骤。
- **光害行**：一行到底，显示所在 5′ 网格单元的人工亮度（mcd/m²）、换算 Bortle 等级与**光害数据版本**（取光害网格文件头 `dataVersion` 的短显形式，如「Falchi 2016 图谱 · 全量网格 2026-10-27」；数据替换后随文件头自动更新，图文口径一致）。该值为网格区域值，非测点精值，卡面以「光害 · 区域值」字样标明。
- **无数据兜底**（产品文案口径）：坐标无网格数据时，卡内文案为「光害 · 暂无网格数据」，并就地给出手动 Bortle 选择（1–9）；选定后该行显示所选等级并标注「手动 Bortle」。

### 7.3 日期切换

- 默认显示当晚。控件形态：日期步进（◀ ▶）+ 点按日期打开日历选择。
- 标注方式：当晚显示为「10月27日 周二 · 今晚」；不在当晚时，日期带相对标注（如「明天 · 10月28日 周三」），并在日期行显示「回到今晚」快捷返回。
- 可切换范围：当晚前 7 天至后 30 天；范围外的步进方向置灰，日历中不可选。
- 随日期联动：时间轴、推荐与状态行均为所选日期之夜；事件小节（日月食、流星雨峰值）取相对所选日期 ±3 天；游标属于所选日期之夜，切换日期时游标复位为无游标态（见 7.5）。计算用例按日期入参、用例内不读系统时钟，此口径不变。

### 7.4 静态四层时间轴（第一期）

横轴覆盖日落前 1 小时至日出后 1 小时，自下而上四层：

- **背景带**：按太阳高度分段着色（日间 / 民用暮光 / 航海暮光 / 天文暮光 / 天文夜）。
- **曲线层**：太阳高度曲线与月亮高度曲线，采样步长 5 分钟；月亮在地平线以上的时段高亮。**月亮曲线旁注当晚月光照明比**（如曲线旁文字「照明 42%」），静态轴即落实，不等游标期。
- **区间层**：低月光窗口与银心可见窗口画为轴上区间带（原低月光文字小节取消）。
- **标记层**：九类关键时刻全部落为轴上标记——日落、民用暮光终、航海暮光终、天文暮光终（天文夜开始）、月出、月落、银心中天、晨光始（天文夜结束）、日出。标记只留刻度、不带文字标签：日落、日出、月出、月落的标记即太阳实线 / 月亮虚线与地平线的交点，文字为重复信息；其余五类（民用 / 航海 / 天文暮光终、晨光始、银心中天）在曲线上读不出准确时刻，同样只留刻度。原「关键时刻」文字小节取消。
- **点按详情**：刻度与曲线交点可点，点按热区为不小于 40dp 的透明区域，不得只有线宽大小。点按弹出详情窗，九类全覆盖：太阳交点 / 日落 / 日出刻度 → 「太阳」详情（日落时刻 + 方位角、日出时刻 + 方位角，所选日期之夜起止各一，方位角在升落时刻经历算端口采样）；月亮交点 / 月出 / 月落刻度 → 「月亮」详情（月出时刻 + 方位角、月落时刻 + 方位角、月相名称 + 照明比）；民用暮光终 / 航海暮光终 / 天文暮光终 / 晨光始刻度 → 时刻 + 对应太阳高度（−6° / −12° / −18° / −18°）；银心刻度 → 中天时刻 + 中天高度。
- **时刻标记防重叠**：文字标签取消后，标签排布与碰撞避让不再需要；刻度按各自时刻位置绘制，时刻密集时点按热区允许重叠，重叠区以后置标记为准。
- **纵轴口径**：纵轴下限随日月采样序列的实际最小值动态取值——最深样本减 5° 边距、向下取整到 5° 步进，并钳制在 [−90°, −5°]：下限不低于 −90°，且始终位于地平线以下至少 5°，使地平线（0°）参考线可读；地平线下较深的曲线段（月亮在地平线下可达约 −60°…−78°，极夜地区太阳亦然）完整呈现，不设固定截断。
- **月相名称分档（本节为主存）**：按月相角 θ（日月黄经差，0–360°，经历算端口暴露）八分，每档 45°、互斥无缺口，每档含下界不含上界：新月 [337.5, 360)∪[0, 22.5)、娥眉月 [22.5, 67.5)、上弦 [67.5, 112.5)、盈凸月 [112.5, 157.5)、满月 [157.5, 202.5)、亏凸月 [202.5, 247.5)、下弦 [247.5, 292.5)、残月 [292.5, 337.5)；英文依次为 New Moon / Waxing Crescent / First Quarter / Waxing Gibbous / Full Moon / Waning Gibbous / Last Quarter / Waning Crescent。功能设计文档（docs/design.md §5.4.1）引用本分档，不另立口径。
- **第二期预留**：静态轴的版式结构中预留游标轨道、气泡层与目标弧段层的位置（轴体高度与分层顺序按 7.5 的游标态版式预留），第二期接入交互时不返工版式。
- **退化与降级落位**：无天文夜时时间轴退化为仅日月曲线 + 明示无夜晚，背景带与低月光层相应缺省。既有降级提示随小节迁移到新位置，一个不少：光害无数据（落地点卡，见 7.2）、目标目录损坏、事件目录不可用、推荐不可用。

### 7.5 游标交互（第二期）

游标态下，时间轴下方推荐区切换为「此时可拍」：

- **拖动与气泡**：在轴上按下即定位、拖动跟随；气泡实时显示游标时刻，并附该时刻的月高与照明比，拖动中即可读到月光条件。
- **吸附**：游标距任一关键时刻 ≤5 分钟时吸附到该时刻，气泡追加时刻名（如「月落 23:36」），并给一次轻震动反馈。
- **精度**：游标时刻以 1 分钟为最小单位。轴下设时间条：−1′ / +1′ 逐分微调，长按连跳为 10 分钟步进。
- **「此时可拍」入选口径**：候选 = 目录内在该时刻高度 ≥20° 且尚未落下的目标；排序先按高度从高到低，同高时月光贡献小者优先。月光贡献沿用低月光窗口现行的 SkyAssembly 采样定义，不另立口径。
- **状态行**：固定给四件事——所处时段（天文夜或暮光段名）、日高、月光干扰三档（无 / 弱 / 强，分界沿用功能设计第 5 节通则二的三分之一线）、低月光窗口归属（在窗口内，或下一个低月光窗口何时开始）。
- **月光干扰三档分界（状态行口径）**：三档互斥——无 = 该时刻无月光贡献；弱 = 有月光贡献，且月光贡献低于光害基线的 1/3；强 = 其余情形，即月光贡献达到或超过光害基线的 1/3（≥1/3）。此分界与功能设计第 5 节通则二的降级线是两条不同的线：通则二的降级线指月光贡献使总天光亮度达到光害基线的约 4 倍以上时，对深空 / 银河目标作整晚适拍性降级判定；本分界只用于时间轴状态行对单个时刻的干扰分档。两条线用途不同，不得互相套用。
- **弧段联动**：入选目标以其「高度 ≥20° 的时段」在轴上画弧段，中天处画实心点；点列表行高亮对应弧段，点弧段滚动定位到对应行，双向高亮。未入选目标不画弧。
- **退出**：点「看整晚 ✕」回到整晚短名单（现行口径：星等 ≤6.5、中天高度 ≥40°、最亮前 10）；游标位置保留，再次点轴上任意处直接回到该游标时刻。
- **与日期切换的关系**：游标属于所选日期的那一夜，切换日期时复位为无游标态（见 7.3）。

### 7.6 时区口径

- 手动编辑经纬度后，一切时刻按**所选地点坐标对应的时区**计算与显示（以坐标查时区），不按设备时区。
- 显示时区与设备时区不一致时，沿用既有时间健康检查提示（见第 5 节），并在今晚页以一行小字标注当前显示时区名（如「时刻按 America/New_York 显示」）。
- GPS 重新定位后，按新坐标对应的时区计算与显示。

补充（0.4.0 实现口径）：

- **解析方案**：离线内置一份粗粒度的陆地区域框表（轴对齐经纬度框、按具体程度排序、首个命中框为准），坐标 → 时区解析在领域层以纯函数实现（`SiteTimeZone`）。GPS 定位、手动编辑经纬度、收藏地点三条通道走同一解析路径。
- **解析结果**为 `ZoneId`，夏令时切换由 java.time 按该时区的规则处理，应用层不自算偏移。
- **回退口径**：坐标落在一切框外（海洋、中亚、俄罗斯大部、非洲与南美洲部分地区等）时不解析，回退设备时区；今晚页照常以小字显示实际所用时区名，不把回退结果呈现为坐标解析结果。
- **精度边界**：框表是近似——框界与真实时区边界不重合，边界地区可能落入相邻时区；已知简化包括亚利桑那州（随山地时区框处理、与该州大部不实行夏令时的口径不符）、阿留申群岛（随阿拉斯加框）、纽芬兰（随大西洋加拿大框）、印度东北部与中国框交界一带、伊比利亚西侧（葡萄牙框先于西班牙框命中，加利西亚等地解析为 Europe/Lisbon，与马德里相差 1 小时）。此类误差以「界面明示实际时区名 + 时间健康检查」兜底，不静默呈现假精度。
