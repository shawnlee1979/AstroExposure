## 1. 设计定调

- **仪器感**：深空黑底、低饱和、高信息密度、层级清楚；像天文器材的控制面板，不做消费 App 的圆润花哨风。
- **夜间优先**：一切设计先过「黑暗环境」这一关——对比度靠亮度层级而非彩色，强调色克制使用，红光模式为整套独立主题而非滤镜。
- **结论先行**：任何界面第一眼必须看到结论（今晚能不能拍、拍多久），输入与细节在后。

## 3. 信息架构

底部四栏：**今晚 / 计算 / 计划 / 设置**。

- 今晚（首页）：地点卡（定位 + 光害 + 环境同卡）→ 日期切换 → 今晚概览块 → 时间轴（页面主干，整合曲线、区间、时刻标记与推荐联动，规格见第 7 节；今晚目标（0.9.0 起为推荐弹窗、0.10.0 起改全量达标弹窗）由时间轴卡头按钮打开弹窗呈现，页面内不再设独立推荐卡，规格见 §7.8）→ 事件小节。计算类别不在首页出现，在计算页内选择。
- 计算：五类目标的计算器列表 → 输入页 → 结果卡片页。
- 计划：已保存计划（卡片列表）+ 导出 / 导入。
- 设置：设备库（相机 / 镜头 / 跟踪档案）、地点收藏、严苛档默认值、红光模式（含日落后自动）、语言、时间健康状态。

## 4. 关键界面

1. **今晚页**：地点卡（定位 + 光害 + 环境同卡）→ 日期切换行 → 今晚概览块 → 时间轴主干 → 推荐区 → 事件小节；页面不设五类入口，计算类别在计算页内选择；顶部另有时间健康状态。完整规格见第 7 节。
2. **参数卡片（结果）**：卡顶 = 类别 + 严苛档徽章；主体 = 2–4 个大数值（快门 / 光圈 / ISO / 张数）；下方理由列表（每条一句人话，含所用赤纬、图谱角标等）；降级时卡顶整条变 warn 色并直言原因；底部操作：保存计划 / 微调重算。
3. **计算器输入**：分组输入——设备（先选相机、再选镜头）、场景（目标类别相关项）、档位（严苛三档分段控件 + 系统推荐标注）；数值项用大步进器与滑杆组合，禁止小下拉框；底部固定「计算」主按钮。**镜头从镜头库选择，不自由填写焦距（2026-10-26 起执行）**：镜头库 = 内置五家清单 + 用户自定义（含定焦与变焦）；选中后焦距与最大光圈由镜头数据带出。定焦无焦距控件；变焦在该镜头焦段内用滑杆 / 步进选焦距（连续量，保留数值呈现）。想用的镜头不在库里时，入口引导先去设置页镜头库添加自定义镜头，计算器内不设临时填写。光圈选择器的起点随所选镜头联动：变光圈变焦按当前焦段的有效最大光圈（镜头数据支持时），数据只有单一最大光圈时用该值。**光圈为专用控件（2026-10-26 起执行）**：不用自由数值填写，改为标准档位选择器——档位序列取相机通用的 1/3 档名义刻度（1.0 / 1.1 / 1.2 / 1.4 / 1.6 / 1.8 / 2.0 / 2.2 / 2.5 / 2.8 / 3.2 / 3.5 / 4.0 / 4.5 / 5.0 / 5.6 / 6.3 / 7.1 / 8 / 9 / 10 / 11 / 13 / 14 / 16 / 18 / 20 / 22），序列起点为镜头最大光圈（默认停在最大光圈）：比最大光圈更大的档位不出现，如 f/1.2 镜头自 1.2 起、f/1.4 镜头自 1.4 起，终点 f/22；交互为左右步进按钮 + 可横滑的刻度带，吸附到最近档位，不出现相机上不存在的数值。焦距为连续量，保持数值 + 滑杆，不套档位。**输入校验与结果完整性（0.7.1 补条）**：任一输入校验失败（如赤纬不可解析或越界）时，旧结果卡与明细行必须同步清除、就地显示校验提示，不得保留与当前输入不一致的结果呈现；底部「计算」主按钮仅在至少一个计算器被组合时可用，无任何计算器可计算时禁用，不以点按补算。
4. **关键时刻呈现**：九类关键时刻全部落为时间轴上的标记（见 7.4），点按标记弹出该时刻详情；原页尾纵向时刻列表取消。低月光窗口与银心可见窗口画为轴上区间带（见 7.4）。
5. **红光模式**：与深色主题同一布局整套换红阶；开关在设置与首页状态行各一处（一键切换），可选日落后自动开启。

## 5. 状态呈现（与功能设计一一对应，不许粉饰）

- **跟踪档案未实测**：跟踪卡片不给秒数，显示换算公式 + 「待基线实测录入」徽章（warn）。
- **满月降级**：深空 / 银河卡片顶部直言提示条（bad→warn 口径，写死文案模板）。
- **天光为图谱估算**：角标小字，不算降级；手动 Bortle 覆盖后角标变「手动覆盖」。
- **日食安全闸门**：不可跳过的阻断式面板（bad 色顶栏 + 警告标题 + 确认勾选；未确认时不显示任何参数——类型芯片与 ISO 均不渲染，此时点计算只产出阻断提示，域层 SafetyGate 同步拦截）。
- **时间健康异常**：首页状态行红点 + 一行说明（时区不一致 / 时钟偏差）。显示时区与设备时区不一致时，今晚页另以一行小字标注当前显示时区名（口径见 7.6）。
- **地点卡无光害网格数据**：地点卡内明示「暂无网格数据」，并就地给出手动 Bortle 选择（口径见 7.2），不留空、不凑数。

## 6. 交互规则

- 所有计算页遵循同一流：输入 → 大按钮计算 → 结果卡（结论 + 理由）→ 可保存为计划。
- 改任一输入后结果不自动乱跳，点「重算」或防抖 300ms 后刷新并标注已更新。
- 档位切换即时重算并在卡上更新档徽章。
- 返回保留输入；计划卡可一键复用当晚重算。

## 7. 今晚页时间轴整合规格

今晚页以一根时间轴为页面主干：地点卡、日期切换、今晚概览块、静态分层时间轴、游标联动推荐与事件小节按本节口径实现。分期与版本见 7.7。

### 7.1 通则：手机框内只出现产品文案

- 界面与样张的手机框内，只出现真实 App 会有的产品文案：短、直接、面向使用者。
- 设计解说一律放在手机框外的面板或本文档中，框内不混入解说腔（包括「点数字可直接改」这类对设计意图的提醒文字）。
- 本通则适用于全部界面与全部样张。

### 7.2 地点卡与今晚概览块

定位、光害与环境合并为一张卡，置于今晚页顶部；其下依次为日期切换行与「今晚概览」块，再接时间轴：

- **定位行**：进入今晚页默认自动 GPS 定位；停留在今晚页期间每 **5 分钟**静默刷新一次定位（离开页面即停），定位请求不叠加——已有请求在途时新的触发直接跳过；显式点按来源行时若已有请求在途，则认领在途结果（不另起请求、结果照常覆盖，下文「显式点按不受此限」与此衔接）。自动定位（入口自动定位与周期刷新）只作用于 GPS 与示例兜底态的地点：从设置页显式选中的收藏地点、手动输入的地点永不被自动定位覆盖——发起与成功覆盖双重守卫（发起时按当前地点类型判断，刷新在途期间用户改选手动 / 收藏地点时，迟到的定位结果直接丢弃不应用）；显式点按来源行触发的定位不受此限，其结果照常覆盖，这也是从任何地点回到 GPS 的路径。来源行整行可点（热区 ≥48dp），点按即重新定位 / 切到 GPS 并以新结果覆盖，不另设确认步骤、不设独立的定位按钮（「使用 GPS 定位」按钮自 0.8.4 起删除）。定位失败提示只在当前没有任何可用定位、即地点为内置示例兜底态时出现在来源行后；已有 GPS 旧定位时刷新失败静默沿用旧定位、不挂任何警告字样，选中收藏 / 手动地点时同样不显示 GPS 失败字样；刷新成功照旧更新地点并清失败态。坐标行数值前设 GPS 同步点（0.8.6）：当前地点来源为 GPS 时，坐标数值前显一枚状态圆点（状态色「正常」色，红光主题下呈红阶），表示这组坐标由 GPS 同步得到；手动 / 收藏 / 示例地点不显此点。经纬度以数字文本呈现，坐标文字本身即编辑入口，点按文字原地进入编辑、确认即生效（0.8.12 起去掉原数字后的小编辑字形 ✎、不设任何替代标记；编辑入口由无障碍内容描述「点按编辑坐标」承载，不依赖字形）；卡内不设独立的手动输入块。编辑校验：纬度 −90°…90°、经度 −180°…180°，越界输入不生效并就地提示。编辑后来源标记为「手动」。
- **地点识别（0.8.3 新增，0.8.6 扩展到手动地点）**：GPS 定位成功、或手动输入坐标后，自动把坐标与全部收藏地点逐一算距离（球面距离，领域层纯函数），最近收藏点在 **100 m** 内（经验阈值：覆盖手机定位漂移、不吞并真正不同的邻近地点）即视为到达该点：名称行显示该收藏名，来源行注「GPS 定位 · 已匹配收藏地点」（手动地点注「手动经纬度 · 已匹配收藏地点」）；坐标仍显地点本身的值，不吸附到收藏坐标。手动地点经此链识别是 0.8.6 的修复点：此前识别只覆盖 GPS，手动地点保存后不被识别、保存按钮不消失可重复保存。无匹配时名称行只显坐标（无名称行），来源行明示未保存状态：「位置来源：GPS 定位（未保存）」（0.8.5 起实现与此口径对齐，此前回落无标记的「位置来源：GPS」旧串）。

### 7.3 日期切换

- 默认显示当晚。控件形态：日期步进（◀ ▶）+ 点按日期打开日历选择。
- 标注方式：当晚显示为「10月27日 周二 · 今晚」；不在当晚时，日期带相对标注（如「明天 · 10月28日 周三」），并在日期行显示「回到今晚」快捷返回。
- 可切换范围：当晚前 7 天至后 30 天；范围外的步进方向置灰，日历中不可选。
- 随日期联动：时间轴与推荐均为所选日期之夜；事件小节（日月食、流星雨峰值）取相对所选日期 ±3 天；游标属于所选日期之夜，切换日期时游标复位为无游标态（见 7.5）。计算用例按日期入参、用例内不读系统时钟，此口径不变。

### 7.5 游标交互（第二期）

游标态下，时间轴下方只保留加载 / 不可用条带（状态行已于 0.8.4 删除，见「状态行」条）；目标详情在点按弧段后以弹出窗呈现（见「详情弹出窗」条）：

- **拖动与气泡**：在轴上按下即定位、拖动跟随；气泡三行（0.8.9 按对照样张 C 案改组成）：第一行「HH:MM · 所处阶段」——阶段为游标时刻的太阳分段名（白天 / 民用暮光 / 航海暮光 / 天文暮光 / 天文夜）；游标吸附到关键时刻时，时刻名替代时间领起本行（如「月落 23:36 · 天文夜」）；第二行「月高 x° · 月相照明 x%」（月相为月相照明分数，概念分工见下条）；第三行「月光干扰 档位 · 光害 Bortle N 级」——干扰档位取游标评估的档位（见月光干扰三档分界条），光害改显 Bortle 等级、与地点卡环境区同源同口径（图谱有数据取其估计值、无数据取手动等级、两者皆无时本行只剩干扰档位；游标评估未返回前本行先只显 Bortle 等级、档位随后补入）。气泡宽随三行内容自适应（最宽行宽＋左右内距，上限为面板宽 −16dp），锚点自 0.8.13 起改到轨带之下：顶边位于轨带底边之下（顶距由面板顶内距＋轨带高＋轨带下行距三常量推导、不写死数字），覆于日光带 / 月亮带 / 标记行区域，水平位置随游标并钳制在面板内；不压轨带曲线（拖动时游标附近的曲线保持可见）、不压泳道与目标名。（沿革：0.8.11–0.8.12 锚在轨带区、覆住曲线；0.8.9–0.8.10 的泳道区顶部锚点更早废止。）在轨带上点按即定位、按住横拖即平滑移动游标（直接拖动，不需长按抓取；见防误触条的轨带拖动列）。气泡形态自 0.8.7 起为深色卡面＋金边框（红光主题下底与边框走红阶令牌），不再随太阳阶段变色。此为无游标时的首次放置；游标放下后的移动受防误触口径约束（见下条）。**游标竖线（0.8.12 加强，0.8.13 改绘制机制）**：2dp 金线纵贯面板全高——轨带、日 / 月带、标记行、全部泳道、窗口带与整点轴一根到底，衬于约 4dp 的面板底色衬线之上（衬线先行、金线居中其上，成描边观感），压过金色推荐框、浅色弧线与亮的日光带段时仍可读，以便对着每条泳道读游标的相对位置；顶端金色圆钮保留；竖线层序在全部行之上、仅气泡在其上，且不拦截任何手势；跟随模式下游标逐分钟移动时竖线随状态移动，不另设状态。绘制机制（0.8.13 更正）：竖线由面板 Box 自身以 drawWithContent 在其内容之后绘制，上下端点取面板的实测高度（由内容决定的真实高度），气泡移出面板、作为面板外层 Box 的后置兄弟仍画在竖线之上；0.8.7–0.8.12 的实现为面板内一块 fillMaxSize 覆层画布——今晚页是纵向滚动 Column（子项高度约束无界）、面板为 wrap-content，画布 fillMaxSize 在无界高度下塌陷为零高，线身（终点取画布高）自始未在真机出现、只有固定 y＝5dp 的顶端圆钮可见，此前各批「竖线已贯通」的核实均为读代码误判；新画法以构造保证端点来自已布局高度、不可能再塌陷（面板内其他定高行画布不受此病、未动）。
- **时钟跟随（0.8.12 新增）**：游标默认跟随当前时钟。每次进入今晚页，跟随初始化为开：当前墙钟分钟落在所显示时间轴范围内时，游标自动置于「现在」、进入完整游标态（轨带、泳道、气泡、时间条俱全）；今晚页可见期间以 ≤30 秒节拍持续对齐（进入时、回到前台时立即对齐一次），游标分钟与墙钟分钟一致；跟随放置为精确落点——不吸附关键时刻、不给震动。**手动接管即停**：用户以任何方式手动移动游标（轨带点按 / 拖动、面板点按 / 拖动 / 长按抓取、时间条 ±1′ 步进、「看整晚」后点轴恢复保留位置），跟随即关闭、游标钉在用户所放之处，其后节拍不得拉回；泳道点按（开目标详情）与标记点按（开标记详情）不移动游标，不影响跟随。**锁定优先**：游标锁定期间节拍不移动游标（与锁定拦截一切轴上手势同口径），解锁后跟随按开关状态继续。**恢复跟随只有两个入口**：时间条「现在」按钮与重新进入今晚页。「现在」按钮的出现条件为：游标已放置、跟随未在驱动、当前分钟在轴内、且与游标分钟不同；点按后游标跳到当前分钟且跟随重新打开（与步进同属明确意图动作，锁定不拦其出现与点按；锁定期间节拍仍不移动游标）。跟随驱动时，时间条在游标时刻旁以小字「实时」（英文 Live）低调指示；锁定期间跟随暂停，指示仍按跟随开关状态呈现。**「看整晚 ✕」**退出游标的同时令跟随在本次今晚页停留内停用，节拍不得把刚退出的游标放回；离开今晚页再进入时跟随重新初始化为开。当前时刻不在轴内时不自动放置，默认态不变；页面开着且跟随仍开（从未手动接管、未按「看整晚」）时，当前时刻进入轴范围后游标随节拍出现。在轴判据只用所显示的那条轴，不另设日期映射。数据刷新（GPS 5 分钟刷新等）重算出新轴后：跟随开则游标仍对齐现在，跟随关则保留用户所选时刻。跟随判定与状态转移为领域层纯函数（输入：跟随状态、锁定、当前时刻、轴范围、游标现状 → 节拍动作与「现在」按钮显隐），UI 只负责节拍与事件转发。跟随状态转移与手势状态机正交，见防误触条后的转移表。

- **月光干扰三档分界**：三档互斥——无 = 该时刻无月光贡献；弱 = 有月光贡献，且月光贡献低于光害基线的 1/3；强 = 其余情形，即月光贡献达到或超过光害基线的 1/3（≥1/3）。此分界与功能设计第 5 节通则二的降级线是两条不同的线：通则二的降级线指月光贡献使总天光亮度达到光害基线的约 4 倍以上时，对深空 / 银河目标作整晚适拍性降级判定；本分界用于单个时刻（游标评估、目标详情）与整晚判定（概览块，取黄昏银心采样）的干扰分档。两条线用途不同，不得互相套用。

- **弧段泳道热区（0.8.9 改版，0.8.11 改观察式）**：泳道视觉高度保持 26dp 紧凑、行距 5dp；点按热区为不可见的透明覆层逐泳道覆盖（每层高 31dp = 视觉行高 26dp ＋行距分摊 5dp，末行只取 26dp），不靠加大视觉行距保热区（取代 0.6.1 的 48dp 上下扩展口径：紧凑版式下相邻泳道覆层首尾相接、无重叠）。覆层自 0.8.11 起为**观察式点按**：只观察按下事件、从不消费——手势的终局是短时（短于长按抓取的约 300ms）、位移未出触摸容差、且全程未被其他处理者消费的轻点时，才触发打开详情窗；一旦面板拖动或长按抓取接管（事件被消费或位移超容差）即静默放弃。（0.8.9–0.8.10 的覆层是消费型点按，整宽覆层在游标态几乎盖满面板、把面板拖动与长按抓取全部吞掉，游标只剩时间条步进可动，本版为其修复。）面板的直接拖动（无游标时）与长按抓取拖动（已放置时）自泳道起手自此恢复，与轨带拖动并存。无障碍语义保留：覆层带目标名内容描述、按钮角色与语义点按动作，读屏可照常触发。

  - **三步流与步题导航（0.12.0）**：滚动中段按实际使用顺序分三步：先了解目标的高度、方位等信息（第一步），再选择构图——镜头焦距与角度（第二步），最后用手机的罗盘与陀螺仪找目标（第三步）。每步以带序号步题领起：序号徽章（圆形、surface2 底、主文字色数字）加步名（15sp 粗体：「目标信息」「构图」「指向」），步题行上方一条边框色分隔线，步题距上一块加大留白（合计 ≥20dp）；步题不可点、无完成态，序号与步名不用金（金只给结论）；步题的无障碍语义为「第 N 步，共 M 步」。滚动区顶部设步题导航行：每步一枚筹片（与步题共用步名串、加序号前缀，热区 ≥48dp），点按平滑滚动定位到对应步题；导航行可横向滚动——长文案语种在窄屏对话框放不下时筹片不被裁切、逐枚可点到（内容放得下时呈现与行为不变，0.12.1 补）；导航只移动滚动位置，不改变订阅、评估与任何行为。步的存废按主体定：第一步与第三步恒在；第二步在主体有可构图内容时存在——深空、星座有取景区与构图区，广域看点只有构图区一节（步题照常、不补替代块），流星雨辐射点取景区与构图区双双缺席、第二步整步缺席且不设明示行，序号按呈现顺序重编（辐射点为「1 目标信息、2 指向」），导航行同步只列实际存在的步。建议焦距与参考焦距两格留在第一步网格第 6 行：它是第二步取景图默认焦距的出处（§7.10 既定派生），先知建议、再行构图；且保住「全窗数据只此一网格」的整合口径，无取景图的看点其焦距两格也有稳定的家。加载中与评估失败时滚动区不出任何步题——三步数据同出一次评估，未成时只呈现占位 / 失败卡（见保留口径失败分支、固定头尾照常），不立空步题。
  - **固定头（结论区）**：目标名为窗标题；其下元信息行一行小字（text2）：类型 · 星等 · 所属星座（目录无星座字段者缺省不显示；星座显本地化名称——目录存 IAU 三字母代码，界面按当前语言显 88 星座全量映射的名称，如 And 显「仙女座」/「Andromeda」，未知代码回退显代码本身，不留空、不编名）；结论行一句结论、金色（accent），由游标时刻阶段、推荐区间游标三态与相对最佳明示拼装（如「现在可拍 · 正在推荐区间内」/「22:14 起进入推荐区间」/「今晚整晚最高 24°，相对最佳在 23:10」/「尚未升起 · 21:47 升起」），为全窗唯一的金色大字行。右上角关闭 ✕ 热区 ≥ 48dp，与点击遮罩关闭、系统返回并存。
  - **固定警告条**：紧贴固定头之下、滚动区之上，条件出现、固定不滚走、不折叠、不进网格。承载月光剔除级提示（月亮在地平线上、夹角 < 40° 且干扰强档时的直言文案）与满月降级类提示。形态沿用全仓统一口径：bad 用粗实线顶栏 + ▲，warn 用虚线边框 + !（红光下同样靠亮度 + 图标 + 线型三通道，见边界态表）。
  - **指向区（第三步「指向」，滚动中段末块）**：罗盘圆盘 + 右侧竖直高度尺的组合控件，下带差值读数与合成行。落点沿革：0.8.0 决议 Q1 曾定指向区排在关键数据网格之前（设想开窗主用途为到现场找目标、指向是第一动作）；0.12.0 按实际使用顺序改订为三步流末步——先看目标信息、再定构图、最后举机指向，改订登记见功能设计第 11 节补充行。本节其余各条（罗盘、高度尺、姿势、读数、对准、真北、提示、订阅）均为指向区自身口径，随卡平移、一字不变；订阅时机尤其不随落点改变：仍是数据就绪后才订阅，不改为滚到第三步才订阅。精度低校准提示与非当前时刻提示是动作级提示（指向动作的数据质量与时刻基准），随本区留在卡内，不升入固定警告条（判定级），两者分级不混。
    - 罗盘：圆形刻度盘，直径约 200dp，盘面随手机朝向反向旋转，盘顶固定机头向标记 ▼（text2 色），▼ 压住的刻度即当前机头向（真北口径）；刻度每 15° 一短刻、每 45° 一长刻，N / E / S / W 四主方位字母（N 用 text 主色，其余 text2），每 90° 象限内标一个数字（90 / 180 / 270，text3 小字）；盘心保持空，机头向数字读数不放盘面。目标方位以金色菱形 ◆ 压在盘缘刻度上（位置 = 游标时刻目标方位角），菱形外加一圈细金环，标记旁不贴数字标签。
    - 高度尺：竖直轨与罗盘等高并排（高约 200dp），底端 0°（地平线，横贯短线 + 「地平线」小字）、顶端 90°，每 15° 一刻，30° / 60° 标数字；目标高度为金色横线贯穿尺宽，右端标目标高度值（金，等宽）；当前仰角为实心三角标记贴尺左缘，标记以下轨段以 surface2 提亮填充。0° 线以下预留约 12dp 带斜纹区段（负高度区），仅用于呈现目标未升起 / 已落下，当前仰角不进入此区。
    - 持机姿势（全窗唯一口径）：竖直持机（竖屏），手机顶边即指向——竖握手机于面前、屏幕朝向自己、顶边朝前上方，仰角 = 顶边指向与水平面的夹角；先按罗盘转身对准方位，再保持方位缓抬顶边对高度。姿势相关提示文案一律按此口径写，不设第二种持机解释。
    - 差值读数（指向区下沿）：方位行与高度行两行等宽大字（≥ 16sp）+ 一行合成行（小字，text2）。方位行：`右转 24°` / `左转 8°` / `目标在正前方`（由带符号最短角差生成，进入对准时只显示后者，不显示「右转 0°」；对准态方位行文案全节统一为「目标在正前方」，与下条对准呈现口径一致）；高度行：`再上抬 5°` / `再下压 12°` / `高度已对准`。合成行：双未准时给操作顺序提示（如「先转方位，再调高度」），单轴对准时提示先完成另一轴，双对准时升为金色结论「目标应在视野中央附近」（按传感器精度留余量，不写「正中」）。
    - 对准判定与滞回：双轴同口径——进入对准 |Δ| ≤ 3°，退出对准 |Δ| > 5°，3–5° 之间保持上一状态。单轴对准呈现走三通道：① 盘顶 ▼ 变金；② 目标菱形的金环加粗，并在菱形与盘顶之间连一条金色短弧（对准扇区）；③ 对应差值行文字变金（方位行改为「目标在正前方」）。双轴同时对准时指向卡整圈边框变金（2dp），合成行升为结论，并给一次轻震动（与游标吸附的既有轻震动口径一致；同一开窗会话内重复进出不重复震动超过每 10 秒一次）。
    - 真北修正：传感器给出磁北口径朝向，磁偏角由端口适配层按地点与日期调平台 `GeomagneticField` 计算并修正，端口对外只出真北值；domain 与 UI 不接触磁偏角与平台类（端口定义见 ADR-0004）。
    - 非当前时刻提示：指向对象为游标时刻的目标方位（与窗内全部数据同口径）；游标时刻与当前时刻相差 > 5 分钟时，指向区上方加一行 warn 小字（如「指向按游标时刻 23:42 计算，与当前天空差 38 分钟」），不自动切换为当前时刻、不禁用指向；相差 ≤ 5 分钟不提示。
    - 精度低校准提示：精度档为低或不可靠时，指向区下方出现一条可消的细提示（info 描边样式，非警告色、不阻断）：「指南针精度低：手持手机在空中画「8」字数次可校准」，右侧 ✕ 关闭、仅对本次开窗有效；精度恢复到中以上时提示自动消失。关闭后的再现语义定死：关闭后即使精度先恢复到中以上、再跌回低档也不再现；仅当精度恶化为不可靠时可再现一次，在不可靠档关闭后本次开窗内同样不再现。精度低时差值读数照常显示，提示条本身即降级标注，不弹窗、不遮挡指向区。读数中断（无读数）期间校准提示一并压制不显示——中断时呈现的样本冻结在最后一帧、其精度档不代表当前状态，不据此驱动提示；读数恢复后按上述关闭 / 再现语义继续处理（此口径与无读数冻结呈现一致，代码自 0.8.1 起实现，本条为 0.8.5 补入规格）。
    - 刷新与订阅生命周期：目标方位 / 高度在开窗时按游标时刻取一组评估值，其后每 30 秒经同一评估入口以同一游标时刻重算一次（不直连历算端口另起路径）；传感器读数经适配层低通平滑后以约 5 Hz 驱动盘面与高度尺重绘。数据就绪后指向区才订阅传感器，关窗立即退订；评估失败时不订阅。游标时刻在开窗期间被真实时间跨过时不处理，窗内数据不随真实时间推进而改（30 秒同值重算除外）。
  - **数据网格（第一步「目标信息」，两列，0.8.2 整合）**：全窗数据只此一张网格，固定 6 行 × 2 列，标签（text3 小字）+ 等宽数值，与全 App 网格样式一致；行序与配对定死：第 1 行高度（游标时刻）| 方位（游标时刻）；第 2 行赤经 | 赤纬（目录值，格式沿用既有呈现口径：赤经 %.2f h、赤纬 %.1f°）；第 3 行中天时间 | 中天高度（全窗只此一份）；第 4 行可拍窗口（整晚 ≥20° 窗口起止；整晚不达 20° 时格显 — 并在格下小字注「整晚不达 20°」）| 推荐区间（起止）——可拍窗口与推荐区间均为 ≥ 阈值连续段与当晚天文夜的交集（无天文夜时取日落至次日日出），交集为空即按无窗口呈现（0.8.4 起；时间轴泳道弧段仍按整轴绘制，不受此口径影响）；再无日落 / 日出可取（极昼 / 极夜，无天文夜且无升落时刻）时无夜界可交，两窗口沿用整轴原始窗口——此时时间轴为正午至次日正午的 24 小时轴，窗口即轴内 ≥ 阈值连续段与推荐段，照常按起止呈现（0.8.6 补明）；第 5 行距月夹角 | 月光干扰档（强 / 弱 / 无）；第 6 行建议焦距（建议焦距区间）| 参考焦距。游标相对推荐区间的状态（在区间内 / 还有 X 分钟进入 / 已过）只由固定头结论行承载，不在格内重复。缺失数据格显 —，不编造数值。网格下方为小字注区（三行皆条件出现，除构图注外）：推荐区间为相对最佳模式时注「整晚最高仅 XX°，推荐区间为相对最佳时段」；月光夹角 40–60° 或弱档的中性提醒（见月光夹角条）；构图注一行（构图建议的文字余量：参考焦距下的长边占比，或封顶 / 无尺寸数据的诚实明示——第 6 行在封顶与无尺寸时两格显 —，原因只在构图注里说，不静默空白）。月亮在地平线下时距月夹角照常显示，夹角格下小字注「月亮在地平线下，仅供参考」。游标时刻高度 / 方位同时是罗盘与高度尺的目标值来源，同一组数只呈现两次（图形 + 数字）。

  - **保留口径（0.7.0 / 0.7.1，本次改版不变）**：**失败分支**——详情评估失败（目录不可用、读取异常或目标不存在）时，窗内显示明确的失败文案并可关闭重试，指向区位置以空卡占位、不出罗盘、不订阅传感器；加载中只用占位，失败与加载中必须是两种可区分的呈现，不得以占位冒充失败。**「不达 20°」口径**——本节凡言「不达 20°」指整晚口径：整晚最高不达 20° 的目标无弧段、无泳道、也不存在可点开的详情窗；游标时刻的高度是单时刻数值、阶段可为空窗，两者分开表述、不得混读。**「去计算」映射与赤纬带入**——按目标类别查显式映射表跳对应计算器（现行目录的深空目标 → 深空计算一类），并把目录已有参数带入计算器的同名输入：赤纬带入广域星空计算的赤纬输入（NPF 按赤纬算；深空计算本身不设赤纬输入，不为带入而虚构字段）；无对应计算器的类别不显示按钮、不编造目的地。**落地提示**——跳转落到计算页时，页面顶部给一次性轻量提示，注明来源目标名，并写明赤纬已预填到广域星空计算（落地页为深空计算器、无赤纬字段可核对，文案不得断言该页上可见的预填）；手动切换计算类别（点按已选中类别不算切换）或离开计算页即消失，不常驻、不重复出现。**激活机制取消登记**——0.5.1–0.6.1 的「进入游标态默认激活排序第一、点按泳道切换激活、游标移动保持激活、激活弧段高亮」整套机制已随 0.7.0 改版取消：进入游标态不再默认选定任何目标，游标移动不再评估单个目标，弧段不再有高亮态；详情改为点按时按需评估。0.6.0 的「已被激活钉住的目标落入月光剔除条件时详情不消失」例外随激活机制一并失效：被剔除目标本就不画弧、无泳道可点，例外无所附着；剔除判定本身（集合规则）不变。

- **推荐拍摄区间（0.6.0 新增）**：每个目标按当晚 5 分钟高度采样序列定义推荐区间：阈值 = max（40°，中天高度 − 10°），区间 = 高度 ≥ 阈值且包含中天样本的连续时段。中天高度不足 40° 时阈值改为中天高度 − 10°（相对最佳模式），详情窗须明示「整晚最高仅 XX°，此为相对最佳时段」，不得把整晚低矮的目标包装成优质时段。色条呈现：推荐区间与该目标 ≥20° 弧段的交集在弧段泳道上以亮色边框框出（叠在弧线填充之上，框几何照对照样张 C：1.5dp 线宽、5dp 圆角、纵向内缩 1.5dp、高 23dp；红光主题下边框仍为最亮红阶且框形本身即信息，不只靠颜色）；推荐区间超出弧段的部分不在条上出现，详情窗给完整区间。详情窗注明推荐区间起止与时长，并给游标相对状态三态：在区间内 / 尚未进入（还有 X 分钟进入，并给进入时刻）/ 已过区间。目标整晚不达 20° 时无弧段、无可点泳道，其推荐区间不在界面呈现（用例层仍按全夜采样计算）；采样序列不存在等退化情形下无区间，如实缺省不编造。
- **月光夹角与剔除（0.6.0 新增，0.7.0 修订）**：夹角指游标时刻目标与月亮的**真实球面夹角**（由两者的水平坐标经球面余弦定理求得）；高度差只是夹角的下界，任何界面与规则不得把高度差当作夹角使用。剔除规则只作用于游标态的可拍集合：月亮在地平线以上（月高 > 0°）且夹角 < 40° 且该目标方向的月光干扰为强档（贡献 ≥ 光害基线 1/3，档位定义见上）三者同时成立时，该目标在该时刻不列入集合——不画弧、不占前 10 名额；剔除在排序与显示上限之前生效。0.6.0 曾有「已被用户点选激活（钉住）的目标在游标移动后落入剔除条件时，详情不消失、卡内以错误色注明」的例外，0.7.0 随激活机制取消而失效，在此登记：被剔除目标本就不画弧、无泳道可点，例外无所附着；剔除判定本身（集合规则）不变。详情窗常驻数据项**与月亮夹角**（游标时刻，整数度），与干扰档并列一行；月亮在地平线下时夹角照常显示并注明「月亮在地平线下，夹角仅供参考」，不触发任何剔除；夹角在 40°–60° 之间、或干扰为弱档时（且未达剔除条件），给一行中性月光提醒（含夹角与档位）。整晚短名单（非游标态）不受本规则影响，口径不变。
- **月相照明与月光贡献的概念分工（0.6.0 新增）**：界面上的两个月亮数字是不同概念，不得混用。**月相照明**（照明比）= 月面被照亮的比例，只随月相变化、与月亮高度无关：满月后整晚可由 95% 缓降至 94%，刚升起的满月与中天的满月照明相同。**月光贡献** = 月光在地面造成的天光亮度，由贡献模型按照明比、月亮高度（大气消光）与目标—月亮夹角算出：月亮刚升起（高度约 1°）时消光极强，贡献远小于中天时——概览块与详情窗的干扰档、以及上条剔除判定，用的都是贡献而非照明比。凡「照明」与月高并列出现处（时间轴月亮曲线旁注、月亮详情窗），文案一律标「月相照明」，不裸写「照明」以免被读成亮度；游标气泡第二行自 0.8.9 起为「月高 x° · 月相照明 x%」，其中「月相照明 x%」即月相照明分数（见「拖动与气泡」条）。

- **防误触（0.5.2 新增）**：游标定好位置后，误碰轴面不得把它移走。手势状态机如下（「步进」指时间条 −1′/+1′ 点按与长按 10′ 连跳）：

  | 状态＼动作 | 点按 | 直接拖动 | 长按拖动 | 轨带拖动 | 步进 |
  |---|---|---|---|---|---|
  | 无游标 | 放置 | 放置并跟随 | 放置并跟随 | —（轨带不出现） | 无游标可步进 |
  | 已放置·未锁定 | 不移动 | 不移动 | 抓起后移动 | 直接移动 | 可用 |
  | 已放置·已锁定 | 不移动 | 不移动 | 不移动 | 不移动 | 可用 |

  长按重定位：已放置（未锁定）时，在轴上按住约 300ms（不超出触摸容差范围）即「抓起」游标，给一次轻震动反馈，之后拖动跟随、松手落位；吸附对长按拖动的落点照旧生效。首次放置不受此限（无游标时点按/拖动照旧）。**轨带拖动（0.8.11 新增）**：日月轨带（见 §7.4）只在游标态出现，是为顺畅 scrub 而设的专用拖动面——在轨带上点按即定位、横向拖动直接跟随，不需长按抓取，是已放置状态下「直接拖动不移动」的唯一例外；纵向为主的滑动仍让给页面滚动（与面板拖动同一方向判定）；锁定后轨带手势同样不移动游标。弧段泳道点按（出目标详情窗）与标记热区点按（出详情）不受影响、语义不变。锁定开关：时间条上设「锁定 / 已锁定」切换钮（锁定态以填充 + 文案双通道呈现，不只靠颜色），只在游标态出现；锁定后轴上点按、拖动、长按一律不移动游标，步进仍可用（明确意图动作）；「看整晚 ✕」退出后点轴回到保留位置是恢复而非新放置，锁定不拦。锁定状态与游标同属所选日期之夜，切日期一并复位为未锁定无游标态。

- **显示口径（0.5.0 实现，0.5.1 修订，0.5.2 再修订，0.7.0 修订）**：轴上弧段只显示排序后的前 10 个（与整晚短名单的上限一致），其余达标目标不画弧。轴下不显示达标计数行（0.5.2 起删除；0.7.0 起轴下仅余状态行，0.8.4 起状态行亦删除、仅余加载 / 不可用条带）；目录加载失败时只显示不可用提示，不留计数空行。弧段按目标的 5 分钟采样序列绘制（采样分辨率即弧段端点精度；弧段的收尾开区间终于轴终点而非最后一个采样点）。
- **吸附落点口径**：关键时刻带秒级精度，游标的最小单位是 1 分钟，吸附落点取关键时刻截断到整分的值，气泡时刻名只在游标确实落在（截断后的）关键时刻上时显示；时间条步进不做吸附。时间条长按语义：按下先步进 1′，持续按住超过约 0.45 秒后改为每约 0.16 秒步进 10′，松开即停。
- **气泡回退口径**：游标评估未返回时，气泡的月高与月相照明都由时间轴自身 5 分钟采样在游标时刻插值得到，所处阶段由同一采样的太阳高度插值后按分段阈值分类，三者描述同一时刻；评估返回后换为该时刻的历算精确值。月光干扰档位只在评估中产生，未返回前第三行只显 Bortle 等级。光害（Bortle 等级）为地点级数值，不随游标时刻变化。
- **块内文字省略规则**：目标名放不下时省略号截断；日光带短标与标记行标注按优先级省略（见 §7.4）。文字一律不缩字号、不与相邻元素重叠。泳道内自 0.8.9 起不标中天文字（见弧段形态条），本条旧款「中天标注宽度规则」随之废止——中天数字由详情窗与气泡承载。
- **详情窗的跨类别适配（0.9.0）**：详情窗自 0.9.0 起同时承载星座、广域看点与流星雨辐射点主体（元信息行、网格标签、焦距派生与「去计算」落点各按主体类别适配），口径见 §7.8；深空目标的既有呈现不变。
- **全画幅构图建议口径**：按 36.0×24.0mm 画幅计算：长边视场角 = 2·atan(18/f)，占比 = 目标长轴角尺寸 / 长边视场角；建议焦距区间为占比 1/3（短焦端）至 2/3（长焦端），并给出占比 1/2 的参考焦距与占比。参考焦距的定义定死（0.8.5 补明）：使目标长轴约占画面长边 1/2 的焦距，即建议区间中点口径（占比与焦距近似线性，近似等于两端焦距中点）；构图注所报占比始终按参考焦距重算，与网格内焦距数字自洽——区间口径变化时注脚随定义走，不单独写死百分比。边界：目录无角尺寸 → 不给焦距建议，详情窗内明示无尺寸数据；理想焦距整体超出 24–2000mm 常用范围 → 不报范围，改给 2000mm（目标过小）或 24mm（目标过大）处目标占长边的比例；范围部分越界时按界钳制并按钳制后的参考焦距重算占比，所报数字始终自洽。呈现（0.8.2）：详情窗数据网格第 6 行两格给建议焦距区间与参考焦距，占比余量与封顶 / 无尺寸明示为网格下方构图注（见「数据网格」条）。

### 7.6 时区口径

- 手动编辑经纬度后，一切时刻按**所选地点坐标对应的时区**计算与显示（以坐标查时区），不按设备时区。
- 显示时区与设备时区不一致时，沿用既有时间健康检查提示（见第 5 节），并在今晚页以一行小字标注当前显示时区名（如「时刻按 America/New_York 显示」）。
- GPS 重新定位后，按新坐标对应的时区计算与显示。

补充（0.4.0 实现口径）：

- **解析方案**：离线内置一份粗粒度的陆地区域框表（轴对齐经纬度框、按具体程度排序、首个命中框为准），坐标 → 时区解析在领域层以纯函数实现（`SiteTimeZone`）。GPS 定位、手动编辑经纬度、收藏地点三条通道走同一解析路径。
- **解析结果**为 `ZoneId`，夏令时切换由 java.time 按该时区的规则处理，应用层不自算偏移。
- **回退口径**：坐标落在一切框外（海洋、中亚、俄罗斯大部、非洲与南美洲部分地区等）时不解析，回退设备时区；今晚页照常以小字显示实际所用时区名，不把回退结果呈现为坐标解析结果。
- **精度边界**：框表是近似——框界与真实时区边界不重合，边界地区可能落入相邻时区；已知简化包括亚利桑那州（随山地时区框处理、与该州大部不实行夏令时的口径不符）、阿留申群岛（随阿拉斯加框）、纽芬兰（随大西洋加拿大框）、印度东北部与中国框交界一带、伊比利亚西侧（葡萄牙框先于西班牙框命中，加利西亚等地解析为 Europe/Lisbon，与马德里相差 1 小时）。此类误差以「界面明示实际时区名 + 时间健康检查」兜底，不静默呈现假精度。

- **分类门槛与配额**：深空沿既有口径（星等 ≤6.5、当日过境中天 ≥40°、按星等升序取舍）；星座：中心中天 ≥40° 且夜切可拍窗 ≥2 小时；广域看点：锚点中天 ≥25° 且夜切可拍窗 ≥1 小时；后两类组内按中天高度降序。配额深空 ≤5、广域 ≤3、星座 ≤2，**不跨类转借**（某类空缺不补给其他类），**筛选不回填**（组榜先于筛选、与筛选无关）。榜单行序按推荐区间起点升序（相对最佳窗的起点同样计入），同起点按中天时刻、再按主体 id 定序。组榜装配同时输出**达标集**（0.10.0）：每类门槛通过者的全量（截断前、类内序同组榜取舍序）、辐射点达标集（入选三条件通过者全量），榜成员由装配自身标记（不按配额名义数推断——某类未满额时标记数即实际榜数）——目标弹窗只呈现此输出，呈现层不另算第二套。
- **可拍窗与推荐区间**：与既有口径同一定义——可拍窗为高度 ≥20° 采样段与天文夜（无天文夜时日落至次日日出）求交的总长；推荐区间为 §7.5 既有推荐窗口（中天 ≥40° 取 ≥max(40°, 中天−10°) 的中天段、低中天取相对最佳并如实标注），同样与夜界求交；整晚样本全程不达 20° 的主体给「整晚不出地平线 20°」事实行。
- **泳道**：整晚态泳道 = 榜单主体（顺序同榜单）+ 辐射点泳道（置于其后）；游标态泳道 = 游标评估集 + 辐射点泳道。星座 / 看点以中心 / 锚点过境绘弧，形态同深空。辐射点泳道：虚线弧 + 信息蓝填充，**无金框、无中天金填充**；辐射点中天进标记行（「辐射点中天」）；入选三条件同时成立才出现——流星雨处于活跃期、今晚距峰值 ≤3 天、辐射点夜切可拍窗 ≥1 小时；同一流星雨在「近期事件」小节的呈现与泳道成员是两套口径，不互相牵动。

- **类目筛选**：时间轴卡头行下设筹片行，四类（深空 / 广域 / 星座 / 流星雨）各带**今晚泳道条目数**，多选、默认全开，**不持久化**（离开页面即复位）。筛选是纯显示层：只作用于泳道与目标弹窗，不改变组榜、配额与详情可达性（被筛掉的主体经其他入口打开详情不受影响）。**两套计数口径并存且不互污**（0.10.0）：筹片计数为泳道口径（整晚泳道条目数、两态恒定）；目标弹窗与按钮角标为达标口径（达标集计数、随筛选变化）——达标集再大，筹片数字也不动。面板下不设筛选事实行：被隐藏类别与全部类目关闭均不在面板下出现任何说明行（0.9.2 起移除；此前 0.9.0–0.9.1 曾设被隐藏类别逐行点名与「已关闭全部类目」两类行）；全部关掉时面板只剩环境带与标记行，筹片行保持可点，不留死局。日月食永不为泳道，不入筛选。

### 7.9 地景构图窗（0.9.1）

地景构图回答的是「地景在画面里定死之后，天体什么时候走到它上方」：摄影者先选定前景（山脊、灯塔、树线）的方位，再看主体何时进入该方位且高度可拍。本节为构图窗的唯一口径；主体、采样与夜界沿用 §7.8 与 §7.5 的既有定义，不另立第二套。

- **定义**：构图窗 = 主体方位角进入地景方位 ±容差、且主体高度落在 [5°, 55°] 的时段，再与当晚夜界（天文夜；无天文夜时日落至次日日出，与可拍窗同一兜底）求交。方位与高度在时间轴上以既有 5 分钟步长采样（方位经星历端口既有成员取得），时段边界为约束切换点在采样间的线性插值——与轨带曲线交点的同一构造；多个时段不合并、逐段呈现。星座按中心点计、看点按锚点计（区内口径行明示；看点另注「段体向地平延伸」）。
- **容差与高度带**：容差三档 ±5° / ±10° / ±15°，默认 ±10°，为构图区内的会话设置（不持久化、两落点不共享——地景方位是逐次实测的现场量）；高度带 [5°, 55°] 固定，不是设置项（下限避地平附近的消光与遮挡，上限避广角镜头下主体脱出地景构图的经验带）。
- **输出与最佳时刻**：每段给起止 + 时长、最佳时刻（金色行）、段内高度范围。最佳时刻取段内方位角精确穿越地景方位的瞬间（插值求解）并附穿越高度，三种形态如实区分：①穿越在段内——「最佳 HH:MM · 穿越高度 N°」；②整段在方位带内但不穿越（方位擦过）——段内最接近点并明示残差「距正中 N°」；③穿越存在但被夜界裁掉——窗内更近的端点为最佳，文案并记真实穿越时刻在天文夜外，不把端点冒充穿越点。
- **空态三诊断**（不留空白、不给假窗）：①时段存在但全在天文夜外——明示「构图时段全在天文夜外（暮光中）」并照常列出该时段（它仍是可拍的暮光构图信息）；②方位带被进入、但带内高度全程在 [5°, 55°] 之外——按方位带内高度范围指明低于下限 / 高于上限 / 跨带未落入；③整夜不进方位带——给最接近的方位差与出现时刻。须注意主体在地平线下方位仍持续旋转：晨昏地平线下绕行可使方位「接近」地景方位而高度深负，此类归诊断②，不得写成③（金样本夜银心对 90° 实测为高度约 −53° 处进入方位带，已按此判）。
- **方位输入**：地景方位一个字段、两个写入口。数字步进：点按 ±1°、长按切换 ±5° 连步（游标时间条步进键的同一纪律，语义动作与内容描述齐备）；罗盘捕获：点按后才订阅 DeviceOrientationProvider（与指向区同一端口），实时显当前朝向，「定住」把读数取整写入同一字段并退订，取消不改值；精度低 / 不可靠时显既有校准提示；无方向传感器时捕获按钮禁用并给明示行。方位按 [0°, 360°) 回绕。
- **落点两处，共用同一构图区组件与同一用例评估**：①目标详情弹窗内，位于注记行之后——主体即当前条目（深空 / 星座 / 看点），计算复用调用方已构建的时间轴；②地景星野计算器内，位于地景帧拍法选择之上——主体可选：银心（看点目录的银心锚点，固定位）/ 广域 / 星座 / 深空四组筹片 + 组内下拉，选主体同步按 §7.8 既定规则把赤纬带入天空帧字段（赤经不动）；目录失败时整块降级为明示不可用行，不编造主体。两处评估均有 200ms 去抖（与游标评估同一纪律），步进不逐值评估。
- **存入计划**：计算器落点的保存把构图三行附入计划正文——「构图窗：主体 · 地景方位 N° · 容差 ±N°」「构图时段：HH:MM–HH:MM / …」（暮光诊断附注、其余诊断写诊断原文）「构图最佳：HH:MM / …」（无时段时显「—」）；计划载荷（payload）不变，计划层不存构图参数。
- **不上主时间轴**：构图窗不进时间轴泳道、不占组榜与筛选；区内以迷你时间条呈现整晚——条上深段为天文夜、金段为构图时段（暮光时段以轮廓色段呈于夜段之外）、金线为各段最佳时刻，带无障碍内容描述。
- **辐射点除外**：流星雨辐射点不设构图区（辐射点不是可定格构图的主体），其详情窗不出现构图控件，不给假输入。
- **金样本口径**：固定金样本夜（Alpharetta，2026-10-27）两例由自动化测试锁定。猎户座对 150° ±10°：时段 03:11:07–03:46:25、穿越 03:38:40 / 高度 54.2°，与设计稿 §5 的示例数字（03:10–03:46、穿越 03:37 / 54°）在约 2 分钟 / 0.3° 内互合（差异为样张取整）。银心对 210° ±10°：实算时段 18:22:33–20:00:51、穿越 19:08:46 / 高度 19.9°，与样张 ⑬ 所绘时段（18:47–20:00、最佳 19:07 / 20°）的时长、最佳与高度互合，但该夜天文暮光终为 20:13，整段在其之前——按 §7.8 既定口径（样张日落与天文夜时刻约慢 1 小时、实现与验收以规则与星历实算为准），App 如实报诊断①「全在天文夜外」，样张 ⑬ 的「夜窗」呈现不成立，此为样张偏差、非实现偏差，不为凑样张改判。

### 7.10 取景图（0.11.0）

取景图回答的是「这个焦距、这个朝向，全画幅框得进什么、切掉什么」：以星图呈现主体与取景框的相对关系。本节为取景图的唯一口径；与 §7.9 分名分立——§7.9「构图窗」管地景方位与时段，本节「取景图」管画幅与骨架几何，两节在详情窗中相邻（取景区在注记行之后、构图区之前）。

- **出现范围**：深空目标（须有角尺寸数据）与星座主体出现取景区。广域看点本批不纳入（组件数据形状按可扩展设计、不写死星座 / 深空两形，看点详情不出现取景区）；流星雨辐射点不出图（与构图区除外的同一理由：辐射点不是可定格构图的主体）。无角尺寸数据的深空目标不出现取景区，只在原位置给一行「无角尺寸数据，无法取景」明示，不编造尺寸。
- **数据**：恒星星表 = HYG v4.4 亮星子集（≤6.5 等、实测 8,920 颗，构建期脚本 `build_stars.py` 生成二进制加名表侧表，CC BY-SA 4.0）；星座连线 = d3-celestial（BSD 3-Clause）的 `constellations.lines.json` 转换（`build_lines.py`，按 HYG 星 id 对齐：88 座 / 150 段 / 893 顶点条目，顶点与星表实测最大偏差 0.0085°、断言上限 0.05°；Serpens 上游为两个同 id feature，合并为一座多链）；深空位角由 objects 管线自 OpenNGC 源 CSV 的 PosAng 列回补（576 条中 132 条有值，缺席为 null、永不填 0）。三者均为构建期产物、运行时零联网；App 数据来源页登记 HYG 与连线两条新来源（连线带 BSD 署名与许可文本入仓 `third-party/`）。
- **坐标与投影**：图面中心 = 主体中心（深空取目录坐标、星座取目录中心）。切平面坐标原点在中心、x 向东为正、y 向北——呈现时按「北上东左」出图（东在左为天文图惯例，节内显式标注）。投影按图面对角选：≤90° 用切平面投影（gnomonic），>90° 用球极投影（stereographic，径向 2·tan(ρ/2)）——切换只影响呈现：入框判定恒在切平面内精确算，图面过滤恒用真实球面距离。
- **图面范围**：图面对角 = clamp(1.6 × 框对角，14°，150°)，框对角 = sqrt（长边视场² + 短边视场²)（50mm → 76.7°、348mm → 14° 下限、14mm → 150° 上限）。横竖幅切换只改框、不缩放图面。图面内的星座连线都画：主体所属星座全亮、其余淡显。
- **绘制**：星点按星等 7 档定径（点径／不透明度：≤0.5 等 3.6dp／1.00、≤1.5 等 2.9／0.95、≤2.5 等 2.3／0.89、≤3.5 等 1.8／0.78、≤4.5 等 1.4／0.67、≤5.5 等 1.1／0.56、≤6.5 等 0.85／0.45；数值源为 0.11.0 设计稿的星点档位表），不按光谱填色。标注只三类：有专名的亮星（≤2.5 等，中文名优先）、结论点名的出框命名星（图上以信息蓝圈标出；红光主题下圈与标注走红阶）、邻近深空目标（同图面的其他有尺寸目标，画淡椭圆、标号加本地名）。深空主体按目录长短轴加位角画椭圆（主体色填充约 12% 加描边）；星座主体画骨架连线。图面中心画十字标。右上角标「↑ 北 · 东在左」与「图面 N° · 切平面投影 / 球极投影」。
- **取景框与判定**：框为全画幅 36×24mm（呈现时按当前投影采样描边、广角下边线可弯），框外压暗（约 55% 黑罩，图面外框另描一线）。入框判定精确（切平面内、落在框边算入框）：星座按骨架全部**唯一顶点星**判定，深空按椭圆支撑函数判定（溢出指明由长轴还是短轴负责）。占比读数走既有全画幅构图建议的目录长轴口径（share），不新造——判定与占比是两个口径、并存不矛盾：猎户座目录长轴 20° 在 50mm 下占比约 50%，而骨架南北跨度约 30°，横幅时顶部棒星仍出框。
- **结论行（金色，第一眼）**：全入框时显「全入框」，横竖幅等价时并记「（横 / 竖幅同样全入框）」。切边时按方位分组点名出框命名星：组按组内最亮星排序、组内最亮优先点名，同组无名星并计为「另有 N 颗无名星出X边」；命名出框星超过 5 颗时只点名最亮 5 颗、余者以总数行如实并报（不静默截断）。横竖互换后可全入框时结论尾给方向提示「改竖幅可全入框」/「改横幅可全入框」，横竖皆切则不给。深空椭圆溢出只报轴（「长轴出框」/「短轴出框」），不报方位。结论行后为等宽数量行：「N mm · 视场 长°×短° · 长边占比 N% · 图面 N°」，其下小字口径行（占比按目录长轴计、星座另注骨架全顶点判定）。邻近目标不另设可见名单行：其名称只以图面标注呈现，并并入整图无障碍内容描述（见「红光与无障碍」条）。区脚注记数据来源与许可一行。
- **控件**：焦距对数滑杆 14–2000mm，默认 = 该目标现有建议焦距的派生值（区间取参考焦距、封顶取 2000、无尺寸不出节），常用刻度 14 / 24 / 50 / 85 / 135 / 300 / 600 / 2000 按对数位置标注；镜头库点选行（整库按焦距升序——含用户自定义镜头：定焦点选即设其焦距，变焦设广角端并选中、焦距在其焦段内时读数行附镜头名，再点已选筹片取消选中）＋摆角滑杆 0–180°（步进 1°，摆角 = 框上边方向的方位角、自北向东，竖幅时上边即长边）＋深空且有位角时「对齐位角 N°」键（点击把摆角设为目录位角；无位角数据时该键缺席并在滑杆下给一行小字注）；横幅 / 竖幅分段开关。全部为详情窗会话状态（不持久化、两落点不共享——本节只落详情窗一处）。
- **红光与无障碍**：红光主题下整图红阶（星点与标注走最亮红阶、连线与邻近椭圆走深红、框线与结论走主题主色）。整图带无障碍内容描述 = 结论行 + 数量行 +（有邻近目标时）邻近目标名称段（「同图面：M32 · M110」形式），与视觉呈现及图面标注同源；控件各自带标签与状态语义。
- **金样本与样张口径差异**：金样本由自动化测试锁定（取景判定与日期无关，固定主体与焦距）：猎户座 @50mm 横幅——23 颗唯一顶点星中 4 颗出北边（χ¹、χ² 与西北 2 颗无名星），竖幅全入且结论带方向提示，share 约 50.5%；M31 @348mm——share 50%，摆角对齐位角 35° 时竖幅椭圆全入框、横幅 0° 亦全入框，M32 / M110 同在图面；天鹅座 @85mm 横幅——9 颗唯一顶点星中 4 颗出框（Albireo 出南、κ / ι² 出北、ζ 出南），横竖皆切、无方向提示，share 约 159%。样张两处口径差异在此登记：①样张 ㉔ / ㉖ 的「28 顶点 / 10 颗」数的是连线顶点**条目**（猎户 28 条、天鹅 10 条，含同一颗星被多段重复经过），判定与结论按唯一星计（23 / 9 颗），出框集合在两种数法下一致；②样张 ㉖ 标 ζ 出东边——实算 ζ 位于中心以南约 11.3°、框半高约 8.1°，精确几何为出南边，出框集合与样张一致，边归属以实算为准、样张标注不成立，不为凑样张改判；③样张三张星图的绘制图面与本节图面自动规则不一致，度量分两口径列清：样张 keyline 标注的图面横向宽度为猎户 57°、M31 10°、天鹅 34°（与样张数值口径实算的图面宽 57.1° / 10.4° / 34.3° 相符），本节规则对三例的图面对角为 76.7° / 14° / 46.1°（M31 触 14° 下限，其 keyline 宽 10° 即由该对角按画布宽高比折算）——实现与验收以规则对角为准，样张只作版式与结论形态参照（主样张板并入时已同处登记）。

- **离线崩溃记录（0.11.1）**：应用未捕获异常时，陷阱处理器（MainActivity.onCreate 首行安装）把时刻、版本与堆栈全文同步写入私有目录固定文件 last-crash.txt——写入以异常包裹、绝不二次崩溃，写后转交系统原默认处理器，系统崩溃行为不变。下次启动若记录在，今晚页顶部出现「上次崩溃记录」卡：等宽字体在限高内滚动显示全文，两键「复制」（全文入剪贴板）与「关闭」（删文件、卡消失）；无记录时页面零存在。不联网、不外传、零新增权限；红光主题下按既有红阶呈现，不单做形态。
- **标注绘制约束（0.11.2）**：图面标注（专名亮星、出框命名星、邻近目标三类）的锚点不设界——图面圆盘伸出画布矩形之外、出框星标注随其顶点落在任意远处，锚点越出画布右 / 下缘是常态而非异常。标注一律经安全绘制助手出图：助手按 Compose 文本绘制的锚点派生约束公式（maxWidth = round（ceil（画布宽 − 锚点 x))、maxHeight 同理（画布高 − 锚点 y)，公式与发货 compose-ui-text 字节码核对一致）以纯函数先算决策：任一可用维度 ≤ 0 时跳过该标注（锚点已在画布外、跳过不改变任何可见内容）；其余情形以该公式的正值约束经 TextMeasurer 测量、按原锚点绘制，界内标注的位置、内容与样式与旧 drawText(String) 直绘完全一致。禁止再在图面画布内直调按锚点派生约束的文本重载；此约束由标注约束全量扫描常驻断言（逐标注断言生产决策与公式一致、负约束绘制为 0）。
- **结论与标注口径修订（0.11.2 发布前 / 0.11.3）**：结论行的全入框等价注记在椭圆与骨架两路均落地——当前幅全入框且横竖互换后亦全入框时结论尾带「（横 / 竖幅同样全入框）」，仅当前幅全入时不带，切边结论仍只给方向提示。0.11.2 结论区曾在数量行后条件出现邻近目标行「同图面：M32 · M110」；0.11.3 取消该可见行（富场面同图面目标可达数十、名单行挤压本节的镜头点选与焦距、摆角控件，真机反馈）——名称集与画布绘出的邻近目标集同源，现只经图面标注与整图无障碍内容描述出现，无邻近目标时描述中亦无此段（画布标注不进无障碍树）。邻近目标的标注集与绘制集对齐：绘制集仍按 reach = 图面半径 + 长轴一半入场，凡绘出淡椭圆者必有标注；中心落在图面外者，其标注锚点在切平面坐标上钳制进图面圆盘外接正方形内（与连线裁剪同界），再经标注绘制约束出图。
