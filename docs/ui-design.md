## 1. 设计定调

- **仪器感**：深空黑底、低饱和、高信息密度、层级清楚；像天文器材的控制面板，不做消费 App 的圆润花哨风。
- **夜间优先**：一切设计先过「黑暗环境」这一关——对比度靠亮度层级而非彩色，强调色克制使用，红光模式为整套独立主题而非滤镜。
- **结论先行**：任何界面第一眼必须看到结论（今晚能不能拍、拍多久），输入与细节在后。

### 红光主题（全局替换，护暗适应）
只用红光谱：bg #0A0202、surface #180404、surface2 #220707、border #471512、text #FF7A6B、text2 #D64A3E、text3 #8F2B21、accent #FF9D8A。禁止出现蓝 / 绿 / 白；照片类元素（如示意缩略图）在红光下以红阶呈现。

红光主题的 error 取 #FF4A3D（与 bad 同值）、onError 取 #2B0500（与代码 AstroTheme 的 RedScheme 一致）。

红光状态色（与深色主题的 info / ok / warn / bad 一一对应，全部取红光谱，靠亮度拉开层级）：info #FF9D8A（与 accent 同值）、ok #E5563C、warn #FF7A45、bad #FF4A3D。红光下状态**不单独依赖色相传达信息**：一律「亮度 + 图标 + 线型」三重编码——ok 配 ✓ 图标与实线边框，warn 配 ! 图标与虚线边框，bad 配 ▲ 图标与粗实线顶栏，info 以描边与正文区分。此口径与功能设计「全部界面红光呈现、不依赖红以外的颜色传达信息」一致。

### 字体与度量
- 数值用等宽数字（tabular），结论数值 ≥ 34sp，其余正文 14–16sp，注脚 ≥ 12sp。
- 圆角：卡片 16dp、控件 12dp；卡片内边距 16dp；卡片间距 12dp。
- 触控目标 ≥ 48dp（戴手套操作）；主要操作单手拇指区可达。
- **弧段块内文字裁定**：弧段泳道内的目标名（11sp）与中天标注（10sp）是 0.5.1 定型的块内标签，属数据标注而非注脚，不受「注脚 ≥ 12sp」下限约束；过小不可读的风险以「段宽不足即省略、详情窗必载同一数值」的省略规则对冲（见 7.5）。其余注脚位一律 ≥ 12sp。
- **主题角色表口径**：两套色板按本节角色表**全表定义**（表中角色逐个给值，含 outline/outlineVariant = 本节 border、errorContainer、secondaryContainer 等），以代码中的全表定义为准；代码侧的全表覆盖 Material 角色全集，含当前无组件引用的 primaryContainer / onPrimaryContainer、inverseSurface / inverseOnSurface / inversePrimary、surfaceDim / surfaceBright / surfaceTint 与 scrim（0.8.0 补齐显式取值，红光侧一律取红光谱值）；实际使用到的角色有值只是下限，不构成删减表中条目的理由，禁止任何组件回落库默认色（红光下出现蓝 / 绿 / 白即违规）。info / ok / warn / bad 四个状态色经 LocalStateColors 提供，状态呈现一律配字形通道（ok ✓ / warn ! / bad ▲ 或对应实心标记），不单独依赖色相。

## 3. 信息架构

底部四栏：**今晚 / 计算 / 计划 / 设置**。

- 今晚（首页）：地点卡（定位 + 光害 + 环境同卡）→ 日期切换 → 今晚概览块 → 时间轴（页面主干，整合曲线、区间、时刻标记与推荐联动，规格见第 7 节）→ 短名单 → 事件小节。计算类别不在首页出现，在计算页内选择。
- 计算：五类目标的计算器列表 → 输入页 → 结果卡片页。
- 计划：已保存计划（卡片列表）+ 导出 / 导入。
- 设置：设备库（相机 / 镜头 / 跟踪档案）、地点收藏、严苛档默认值、红光模式（含日落后自动）、语言、时间健康状态。

## 4. 关键界面

1. **今晚页**：地点卡（定位 + 光害 + 环境同卡）→ 日期切换行 → 今晚概览块 → 时间轴主干 → 推荐区 → 事件小节；页面不设五类入口，计算类别在计算页内选择；顶部另有时间健康状态。完整规格见第 7 节。
2. **参数卡片（结果）**：卡顶 = 类别 + 严苛档徽章；主体 = 2–4 个大数值（快门 / 光圈 / ISO / 张数）；下方理由列表（每条一句人话，含所用赤纬、图谱角标等）；降级时卡顶整条变 warn 色并直言原因；底部操作：保存计划 / 微调重算。
3. **计算器输入**：分组输入——设备（先选相机、再选镜头）、场景（目标类别相关项）、档位（严苛三档分段控件 + 系统推荐标注）；数值项用大步进器与滑杆组合，禁止小下拉框；底部固定「计算」主按钮。**镜头从镜头库选择，不自由填写焦距（2026-10-26 起执行）**：镜头库 = 内置五家清单 + 用户自定义（含定焦与变焦）；选中后焦距与最大光圈由镜头数据带出。定焦无焦距控件；变焦在该镜头焦段内用滑杆 / 步进选焦距（连续量，保留数值呈现）。想用的镜头不在库里时，入口引导先去设置页镜头库添加自定义镜头，计算器内不设临时填写。光圈选择器的起点随所选镜头联动：变光圈变焦按当前焦段的有效最大光圈（镜头数据支持时），数据只有单一最大光圈时用该值。**光圈为专用控件（2026-10-26 起执行）**：不用自由数值填写，改为标准档位选择器——档位序列取相机通用的 1/3 档名义刻度（1.0 / 1.1 / 1.2 / 1.4 / 1.6 / 1.8 / 2.0 / 2.2 / 2.5 / 2.8 / 3.2 / 3.5 / 4.0 / 4.5 / 5.0 / 5.6 / 6.3 / 7.1 / 8 / 9 / 10 / 11 / 13 / 14 / 16 / 18 / 20 / 22），序列起点为镜头最大光圈（默认停在最大光圈）：比最大光圈更大的档位不出现，如 f/1.2 镜头自 1.2 起、f/1.4 镜头自 1.4 起，终点 f/22；交互为左右步进按钮 + 可横滑的刻度带，吸附到最近档位，不出现相机上不存在的数值。焦距为连续量，保持数值 + 滑杆，不套档位。**输入校验与结果完整性（0.7.1 补条）**：任一输入校验失败（如赤纬不可解析或越界）时，旧结果卡与明细行必须同步清除、就地显示校验提示，不得保留与当前输入不一致的结果呈现；底部「计算」主按钮仅在至少一个计算器被组合时可用，无任何计算器可计算时禁用，不以点按补算。
4. **关键时刻呈现**：九类关键时刻全部落为时间轴上的标记（见 7.4），点按标记弹出该时刻详情；原页尾纵向时刻列表取消。低月光窗口与银心可见窗口画为轴上区间带（见 7.4）。
5. **红光模式**：与深色主题同一布局整套换红阶；开关在设置与首页状态行各一处（一键切换），可选日落后自动开启。

## 5. 状态呈现（与功能设计一一对应，不许粉饰）

- **跟踪档案未实测**：跟踪卡片不给秒数，显示换算公式 + 「待基线实测录入」徽章（warn）。
- **满月降级**：深空 / 银河卡片顶部直言提示条（bad→warn 口径，写死文案模板）。
- **天光为图谱估算**：角标小字，不算降级；手动 Bortle 覆盖后角标变「手动覆盖」。
- **日食安全闸门**：不可跳过的阻断式面板（bad 色顶栏 + 警告标题 + 确认勾选；未确认时不显示任何参数——类型芯片与 ISO 均不渲染，此时点计算只产出阻断提示，域层 SafetyGate 同步拦截）。
- **时间健康异常**：首页状态行红点 + 一行说明（时区不一致 / 时钟偏差）。显示时区与设备时区不一致时，今晚页另以一行小字标注当前显示时区名（口径见 7.6）。
- **地点卡无光害网格数据**：地点卡内明示「暂无网格数据」，并就地给出手动 Bortle 选择（口径见 7.2），不留空、不凑数。

## 6. 交互规则

- 所有计算页遵循同一流：输入 → 大按钮计算 → 结果卡（结论 + 理由）→ 可保存为计划。
- 改任一输入后结果不自动乱跳，点「重算」或防抖 300ms 后刷新并标注已更新。
- 档位切换即时重算并在卡上更新档徽章。
- 返回保留输入；计划卡可一键复用当晚重算。

## 7. 今晚页时间轴整合规格

今晚页以一根时间轴为页面主干：地点卡、日期切换、今晚概览块、静态四层时间轴、游标联动推荐与事件小节按本节口径实现。分期与版本见 7.7。

### 7.1 通则：手机框内只出现产品文案

- 界面与样张的手机框内，只出现真实 App 会有的产品文案：短、直接、面向使用者。
- 设计解说一律放在手机框外的面板或本文档中，框内不混入解说腔（包括「点数字可直接改」这类对设计意图的提醒文字）。
- 本通则适用于全部界面与全部样张。

### 7.2 地点卡、今晚概览块与状态行分工

定位、光害与环境合并为一张卡，置于今晚页顶部；其下依次为日期切换行与「今晚概览」块，再接时间轴：

- **定位行**：进入今晚页默认自动 GPS 定位。经纬度以数字文本呈现，数字后跟一个小编辑图标 ✎ 示意可编辑，点按数字原地进入编辑、确认即生效；卡内不设独立的手动输入块，也不出现提醒类文案。编辑校验：纬度 −90°…90°、经度 −180°…180°，越界输入不生效并就地提示。编辑后来源标记为「手动」；再次点按定位按钮即以新的 GPS 结果覆盖，不另设确认步骤。
- **地点识别（0.8.3 新增）**：GPS 定位成功后，自动把定位坐标与全部收藏地点逐一算距离（球面距离，领域层纯函数），最近收藏点在 **100 m** 内（经验阈值：覆盖手机定位漂移、不吞并真正不同的邻近地点）即视为到达该点：名称行显示该收藏名，来源行注「GPS 定位 · 已匹配收藏地点」；坐标仍显定位本身的值，不吸附到收藏坐标。无匹配时名称行只显坐标（无名称行），来源行为「GPS 定位（未保存）」口径。
- **海拔行（0.8.3 新增）**：GPS 与手动地点在坐标行下显海拔一行。GPS 定位带海拔时显「海拔约 N m」并注明 GPS 椭球高、精度粗、仅供参考——该值只作呈现，不参与任何历算口径；定位无海拔、或手动地点（无海拔来源）时显「海拔 —」，不编造数值。收藏地点被选中时不显此行（收藏记录的海拔来源不可考，不呈现）。
- **保存为收藏地点（0.8.3 新增）**：当前地点为未保存的 GPS 定位时，卡上出现「保存为收藏地点」按钮；点按弹命名框，确认后把名称、当前坐标与海拔存入收藏——与设置页收藏管理同一存储，不设第二套地点数据；保存后该地点即被识别，名称行显新名、按钮消失。设置页的收藏添加 / 选用 / 删除行为不变。
- **光害行**：一行到底，显示所在 5′ 网格单元的人工亮度（mcd/m²）、换算 Bortle 等级与**光害数据版本**（取光害网格文件头 `dataVersion` 的短显形式，如「Falchi 2016 图谱 · 全量网格 2026-10-27」；数据替换后随文件头自动更新，图文口径一致）。该值为网格区域值，非测点精值，卡面以「光害 · 区域值」字样标明。
- **无数据兜底**（产品文案口径）：坐标无网格数据时，卡内文案为「光害 · 暂无网格数据」，并就地给出手动 Bortle 选择（1–9）；选定后该行显示所选等级并标注「手动 Bortle」。
- **环境区（0.8.3 新增）**：光害行之下设「环境（黄昏时 · 朝向银心）」区，依次三行：光害（上行）、月光贡献（mcd/m²）、总天光（mag/arcsec²，accent 金色，为本区结论值）。月光贡献与总天光即原独立「月光与总天光」块的黄昏时、朝向银心采样，数据源与口径不变，仅搬位置与排版；该独立块自 0.8.3 起取消，天光数字全页只此一份。满月降级直话（口径不变）有则出现在总天光行下方、仍在本卡内；基线来源注（图谱估算 / 手动 Bortle 覆盖 / 无数据）随迁至环境区末尾。无天空上下文时环境区只显无数据文案，不凑数。
- **今晚概览块（0.8.3 新增）**：日期切换行与时间轴卡之间的一块四格信息：天文夜起止（整晚口径，取当晚天文夜窗口；无天文夜时直写「无天文夜」）；日高（游标时刻值，标签注明「日高（游标 HH:MM）」随游标更新；无游标时标签只写「日高」、值显 —）；月光干扰档（整晚判定：黄昏时朝向银心采样的干扰档，与环境区同源同档位定义，见 7.5 三档分界条）；低月光窗口（有则逐个列起止、无则直写「今晚无低月光窗口」，与时间轴低月光带同源）。四项全部取现行已算数据，不新增计算路径。
- **与状态行的分工**：轴下状态行自 0.8.3 起只留「游标时刻 · 所处阶段」（见 7.5 状态行条），日高、月光干扰与低月光窗口归属只在概览块出现，不两处重复。

### 7.3 日期切换

- 默认显示当晚。控件形态：日期步进（◀ ▶）+ 点按日期打开日历选择。
- 标注方式：当晚显示为「10月27日 周二 · 今晚」；不在当晚时，日期带相对标注（如「明天 · 10月28日 周三」），并在日期行显示「回到今晚」快捷返回。
- 可切换范围：当晚前 7 天至后 30 天；范围外的步进方向置灰，日历中不可选。
- 随日期联动：时间轴、推荐与状态行均为所选日期之夜；事件小节（日月食、流星雨峰值）取相对所选日期 ±3 天；游标属于所选日期之夜，切换日期时游标复位为无游标态（见 7.5）。计算用例按日期入参、用例内不读系统时钟，此口径不变。

### 7.4 静态四层时间轴（第一期）

横轴覆盖日落前 1 小时至日出后 1 小时，自下而上四层：

- **背景带**：按太阳高度分段着色（日间 / 民用暮光 / 航海暮光 / 天文暮光 / 天文夜）。
- **曲线层**：太阳高度曲线与月亮高度曲线，采样步长 5 分钟；月亮在地平线以上的时段高亮。**月亮曲线旁注当晚月光照明比**（如曲线旁文字「照明 42%」），静态轴即落实，不等游标期。
- **区间层**：低月光窗口与银心可见窗口画为轴上区间带（原低月光文字小节取消）。
- **标记层**：九类关键时刻全部落为轴上标记——日落、民用暮光终、航海暮光终、天文暮光终（天文夜开始）、月出、月落、银心中天、晨光始（天文夜结束）、日出。标记只留刻度、不带文字标签：日落、日出、月出、月落的标记即太阳实线 / 月亮虚线与地平线的交点，文字为重复信息；其余五类（民用 / 航海 / 天文暮光终、晨光始、银心中天）在曲线上读不出准确时刻，同样只留刻度。原「关键时刻」文字小节取消。
- **点按详情**：刻度与曲线交点可点，点按热区为不小于 40dp 的透明区域，不得只有线宽大小。点按弹出详情窗，九类全覆盖：太阳交点 / 日落 / 日出刻度 → 「太阳」详情（日落时刻 + 方位角、日出时刻 + 方位角，所选日期之夜起止各一，方位角在升落时刻经历算端口采样）；月亮交点 / 月出 / 月落刻度 → 「月亮」详情（月出时刻 + 方位角、月落时刻 + 方位角、月相名称 + 照明比）；民用暮光终 / 航海暮光终 / 天文暮光终 / 晨光始刻度 → 时刻 + 对应太阳高度（−6° / −12° / −18° / −18°）；银心刻度 → 中天时刻 + 中天高度。
- **时刻标记防重叠**：文字标签取消后，标签排布与碰撞避让不再需要；刻度按各自时刻位置绘制，时刻密集时点按热区允许重叠，重叠区以后置标记为准。
- **纵轴口径**：纵轴下限随日月采样序列的实际最小值动态取值——最深样本减 5° 边距、向下取整到 5° 步进，并钳制在 [−90°, −5°]：下限不低于 −90°，且始终位于地平线以下至少 5°，使地平线（0°）参考线可读；地平线下较深的曲线段（月亮在地平线下可达约 −60°…−78°，极夜地区太阳亦然）完整呈现，不设固定截断。
- **月相名称分档（本节为主存）**：按月相角 θ（日月黄经差，0–360°，经历算端口暴露）八分，每档 45°、互斥无缺口，每档含下界不含上界：新月 [337.5, 360)∪[0, 22.5)、娥眉月 [22.5, 67.5)、上弦 [67.5, 112.5)、盈凸月 [112.5, 157.5)、满月 [157.5, 202.5)、亏凸月 [202.5, 247.5)、下弦 [247.5, 292.5)、残月 [292.5, 337.5)；英文依次为 New Moon / Waxing Crescent / First Quarter / Waxing Gibbous / Full Moon / Waning Gibbous / Last Quarter / Waning Crescent。功能设计文档（docs/design.md §5.4.1）引用本分档，不另立口径。
- **第二期预留**：静态轴的版式结构中预留游标轨道、气泡层与目标弧段层的位置（轴体高度与分层顺序按 7.5 的游标态版式预留），第二期接入交互时不返工版式。
- **退化与降级落位**：无天文夜时时间轴退化为仅日月曲线 + 明示无夜晚，背景带与低月光层相应缺省。既有降级提示随小节迁移到新位置，一个不少：光害无数据（落地点卡，见 7.2）、目标目录损坏、事件目录不可用、推荐不可用。

### 7.5 游标交互（第二期）

游标态下，时间轴下方只保留状态行（0.8.3 起为瘦身口径，见「状态行」条）；目标详情在点按弧段后以弹出窗呈现（见「详情弹出窗」条）：

- **拖动与气泡**：在轴上按下即定位、拖动跟随；气泡实时显示游标时刻，第二行固定为「月高 x°，月相 x%，光害 xx」——月相为月相照明分数（改名，概念分工见下条），光害为当前地点光害值，与地点卡同源同口径短显（无数据显 —），拖动中即可读到月光条件。此为无游标时的首次放置；游标放下后的移动受防误触口径约束（见下条）。
- **吸附**：游标距任一关键时刻 ≤5 分钟时吸附到该时刻，气泡追加时刻名（如「月落 23:36」），并给一次轻震动反馈。
- **精度**：游标时刻以 1 分钟为最小单位。轴下设时间条：−1′ / +1′ 逐分微调，长按连跳为 10 分钟步进。
- **可拍集合口径**：候选 = 目录内在该时刻高度 ≥20° 且尚未落下的目标；排序先按高度从高到低，同高时月光贡献小者优先。月光贡献沿用低月光窗口现行的 SkyAssembly 采样定义，不另立口径。自 0.6.0 起，入选前先执行月光夹角剔除（见下条），被剔除者不入选、不画弧、不占前 10 名额。
- **状态行**：自 0.8.3 起只给两件事——游标时刻与所处时段（天文夜或暮光段名）。日高、月光干扰三档与低月光窗口归属原在此行呈现，0.8.3 起移至今晚概览块（见 7.2），轴下不重复；游标评估本身仍产出这三项供概览块与弧段使用，数据路径不变。（0.8.3 之前的状态行为四件事：时段、日高、月光干扰三档、低月光窗口归属，仅为历史。）
- **月光干扰三档分界**：三档互斥——无 = 该时刻无月光贡献；弱 = 有月光贡献，且月光贡献低于光害基线的 1/3；强 = 其余情形，即月光贡献达到或超过光害基线的 1/3（≥1/3）。此分界与功能设计第 5 节通则二的降级线是两条不同的线：通则二的降级线指月光贡献使总天光亮度达到光害基线的约 4 倍以上时，对深空 / 银河目标作整晚适拍性降级判定；本分界用于单个时刻（游标评估、目标详情）与整晚判定（概览块，取黄昏银心采样）的干扰分档。两条线用途不同，不得互相套用。
- **弧段形态（0.5.1 改版）**：入选目标以其「高度 ≥20° 的时段」在轴上画弧段，泳道高约 26dp，目标名以可读字号写在泳道内窗口起点处（单行，超出泳道右界省略号截断）。弧段按中天分段分色：中天段 = 采样高度 ≥ max（20°，当晚最高高度 − 5°）的连续时段（下限不低于可拍阈值），金色填充；其前为上升段、其后为下降段，两段以填充深浅区分。中天段内居中标注「中天 HH:MM · XX°」，红光主题下中天段为最亮红阶且同样带文字标注，状态不只靠颜色。未入选目标不画弧。
- **弧段泳道热区（0.6.1 口径）**：泳道视觉高度 26dp 为既定形态、不变；其点按热区以不可见方式向上下扩展至 48dp（与 §2 触控目标口径一致），扩展区不绘制任何内容，泳道间以扩展区衔接。泳道带目标名的内容描述供无障碍朗读，点按语义与视觉形态不受扩展影响。
- **详情弹出窗（0.8.0 改版，指向助手）**：点按任一弧段泳道，弹出该目标的详情窗（与 7.4 标记详情窗共用同一弹窗组件）。窗形态不变（近全屏宽、高约 80% 屏），内部分三段：固定头与固定警告条不随滚动消失，滚动中段依次为指向区、六行数据网格与网格下方小字注，固定尾不随内容长度漂移。窗内数据口径与本节其余各条一致（游标时刻高度 / 方位、赤经 / 赤纬、中天、可拍窗口与推荐区间、月光夹角与干扰档、全画幅构图建议），指向区只是同组数据的图形呈现，不新增第二条评估路径。
  - **固定头（结论区）**：目标名为窗标题；其下元信息行一行小字（text2）：类型 · 星等 · 所属星座（目录无星座字段者缺省不显示；星座显本地化名称——目录存 IAU 三字母代码，界面按当前语言显 88 星座全量映射的名称，如 And 显「仙女座」/「Andromeda」，未知代码回退显代码本身，不留空、不编名）；结论行一句结论、金色（accent），由游标时刻阶段、推荐区间游标三态与相对最佳明示拼装（如「现在可拍 · 正在推荐区间内」/「22:14 起进入推荐区间」/「今晚整晚最高 24°，相对最佳在 23:10」/「尚未升起 · 21:47 升起」），为全窗唯一的金色大字行。右上角关闭 ✕ 热区 ≥ 48dp，与点击遮罩关闭、系统返回并存。
  - **固定警告条**：紧贴固定头之下、滚动区之上，条件出现、固定不滚走、不折叠、不进网格。承载月光剔除级提示（月亮在地平线上、夹角 < 40° 且干扰强档时的直言文案）与满月降级类提示。形态沿用全仓统一口径：bad 用粗实线顶栏 + ▲，warn 用虚线边框 + !（红光下同样靠亮度 + 图标 + 线型三通道，见边界态表）。
  - **指向区（滚动中段第一块，排在关键数据网格之前）**：罗盘圆盘 + 右侧竖直高度尺的组合控件，下带差值读数与合成行。
    - 罗盘：圆形刻度盘，直径约 200dp，盘面随手机朝向反向旋转，盘顶固定机头向标记 ▼（text2 色），▼ 压住的刻度即当前机头向（真北口径）；刻度每 15° 一短刻、每 45° 一长刻，N / E / S / W 四主方位字母（N 用 text 主色，其余 text2），每 90° 象限内标一个数字（90 / 180 / 270，text3 小字）；盘心保持空，机头向数字读数不放盘面。目标方位以金色菱形 ◆ 压在盘缘刻度上（位置 = 游标时刻目标方位角），菱形外加一圈细金环，标记旁不贴数字标签。
    - 高度尺：竖直轨与罗盘等高并排（高约 200dp），底端 0°（地平线，横贯短线 + 「地平线」小字）、顶端 90°，每 15° 一刻，30° / 60° 标数字；目标高度为金色横线贯穿尺宽，右端标目标高度值（金，等宽）；当前仰角为实心三角标记贴尺左缘，标记以下轨段以 surface2 提亮填充。0° 线以下预留约 12dp 带斜纹区段（负高度区），仅用于呈现目标未升起 / 已落下，当前仰角不进入此区。
    - 持机姿势（全窗唯一口径）：竖直持机（竖屏），手机顶边即指向——竖握手机于面前、屏幕朝向自己、顶边朝前上方，仰角 = 顶边指向与水平面的夹角；先按罗盘转身对准方位，再保持方位缓抬顶边对高度。姿势相关提示文案一律按此口径写，不设第二种持机解释。
    - 差值读数（指向区下沿）：方位行与高度行两行等宽大字（≥ 16sp）+ 一行合成行（小字，text2）。方位行：`右转 24°` / `左转 8°` / `目标在正前方`（由带符号最短角差生成，进入对准时只显示后者，不显示「右转 0°」；对准态方位行文案全节统一为「目标在正前方」，与下条对准呈现口径一致）；高度行：`再上抬 5°` / `再下压 12°` / `高度已对准`。合成行：双未准时给操作顺序提示（如「先转方位，再调高度」），单轴对准时提示先完成另一轴，双对准时升为金色结论「目标应在视野中央附近」（按传感器精度留余量，不写「正中」）。
    - 对准判定与滞回：双轴同口径——进入对准 |Δ| ≤ 3°，退出对准 |Δ| > 5°，3–5° 之间保持上一状态。单轴对准呈现走三通道：① 盘顶 ▼ 变金；② 目标菱形的金环加粗，并在菱形与盘顶之间连一条金色短弧（对准扇区）；③ 对应差值行文字变金（方位行改为「目标在正前方」）。双轴同时对准时指向卡整圈边框变金（2dp），合成行升为结论，并给一次轻震动（与游标吸附的既有轻震动口径一致；同一开窗会话内重复进出不重复震动超过每 10 秒一次）。
    - 真北修正：传感器给出磁北口径朝向，磁偏角由端口适配层按地点与日期调平台 `GeomagneticField` 计算并修正，端口对外只出真北值；domain 与 UI 不接触磁偏角与平台类（端口定义见 ADR-0004）。
    - 非当前时刻提示：指向对象为游标时刻的目标方位（与窗内全部数据同口径）；游标时刻与当前时刻相差 > 5 分钟时，指向区上方加一行 warn 小字（如「指向按游标时刻 23:42 计算，与当前天空差 38 分钟」），不自动切换为当前时刻、不禁用指向；相差 ≤ 5 分钟不提示。
    - 精度低校准提示：精度档为低或不可靠时，指向区下方出现一条可消的细提示（info 描边样式，非警告色、不阻断）：「指南针精度低：手持手机在空中画「8」字数次可校准」，右侧 ✕ 关闭、仅对本次开窗有效；精度恢复到中以上时提示自动消失。关闭后的再现语义定死：关闭后即使精度先恢复到中以上、再跌回低档也不再现；仅当精度恶化为不可靠时可再现一次，在不可靠档关闭后本次开窗内同样不再现。精度低时差值读数照常显示，提示条本身即降级标注，不弹窗、不遮挡指向区。
    - 刷新与订阅生命周期：目标方位 / 高度在开窗时按游标时刻取一组评估值，其后每 30 秒经同一评估入口以同一游标时刻重算一次（不直连历算端口另起路径）；传感器读数经适配层低通平滑后以约 5 Hz 驱动盘面与高度尺重绘。数据就绪后指向区才订阅传感器，关窗立即退订；评估失败时不订阅。游标时刻在开窗期间被真实时间跨过时不处理，窗内数据不随真实时间推进而改（30 秒同值重算除外）。

- **推荐拍摄区间（0.6.0 新增）**：每个目标按当晚 5 分钟高度采样序列定义推荐区间：阈值 = max（40°，中天高度 − 10°），区间 = 高度 ≥ 阈值且包含中天样本的连续时段。中天高度不足 40° 时阈值改为中天高度 − 10°（相对最佳模式），详情窗须明示「整晚最高仅 XX°，此为相对最佳时段」，不得把整晚低矮的目标包装成优质时段。色条呈现：推荐区间与该目标 ≥20° 弧段的交集在弧段泳道上以亮色粗边框框出（叠在分段分色之上；红光主题下边框仍为最亮红阶且框形本身即信息，不只靠颜色）；推荐区间超出弧段的部分不在条上出现，详情窗给完整区间。详情窗注明推荐区间起止与时长，并给游标相对状态三态：在区间内 / 尚未进入（还有 X 分钟进入，并给进入时刻）/ 已过区间。目标整晚不达 20° 时无弧段、无可点泳道，其推荐区间不在界面呈现（用例层仍按全夜采样计算）；采样序列不存在等退化情形下无区间，如实缺省不编造。
- **月光夹角与剔除（0.6.0 新增，0.7.0 修订）**：夹角指游标时刻目标与月亮的**真实球面夹角**（由两者的水平坐标经球面余弦定理求得）；高度差只是夹角的下界，任何界面与规则不得把高度差当作夹角使用。剔除规则只作用于游标态的可拍集合：月亮在地平线以上（月高 > 0°）且夹角 < 40° 且该目标方向的月光干扰为强档（贡献 ≥ 光害基线 1/3，档位定义见上）三者同时成立时，该目标在该时刻不列入集合——不画弧、不占前 10 名额；剔除在排序与显示上限之前生效。0.6.0 曾有「已被用户点选激活（钉住）的目标在游标移动后落入剔除条件时，详情不消失、卡内以错误色注明」的例外，0.7.0 随激活机制取消而失效，在此登记：被剔除目标本就不画弧、无泳道可点，例外无所附着；剔除判定本身（集合规则）不变。详情窗常驻数据项**与月亮夹角**（游标时刻，整数度），与干扰档并列一行；月亮在地平线下时夹角照常显示并注明「月亮在地平线下，夹角仅供参考」，不触发任何剔除；夹角在 40°–60° 之间、或干扰为弱档时（且未达剔除条件），给一行中性月光提醒（含夹角与档位）。整晚短名单（非游标态）不受本规则影响，口径不变。
- **月相照明与月光贡献的概念分工（0.6.0 新增）**：界面上的两个月亮数字是不同概念，不得混用。**月相照明**（照明比）= 月面被照亮的比例，只随月相变化、与月亮高度无关：满月后整晚可由 95% 缓降至 94%，刚升起的满月与中天的满月照明相同。**月光贡献** = 月光在地面造成的天光亮度，由贡献模型按照明比、月亮高度（大气消光）与目标—月亮夹角算出：月亮刚升起（高度约 1°）时消光极强，贡献远小于中天时——状态行与详情窗的干扰档、以及上条剔除判定，用的都是贡献而非照明比。凡「照明」与月高并列出现处（时间轴月亮曲线旁注、月亮详情窗），文案一律标「月相照明」，不裸写「照明」以免被读成亮度；游标气泡第二行自 0.7.0 起为固定格式「月高 x°，月相 x%，光害 xx」，其中「月相 x%」即月相照明分数（见「拖动与气泡」条），属该固定格式的定名，不在此条改名范围内。

- **防误触（0.5.2 新增）**：游标定好位置后，误碰轴面不得把它移走。手势状态机如下（「步进」指时间条 −1′/+1′ 点按与长按 10′ 连跳）：

  | 状态＼动作 | 点按 | 直接拖动 | 长按拖动 | 步进 |
  |---|---|---|---|---|
  | 无游标 | 放置 | 放置并跟随 | 放置并跟随 | 无游标可步进 |
  | 已放置·未锁定 | 不移动 | 不移动 | 抓起后移动 | 可用 |
  | 已放置·已锁定 | 不移动 | 不移动 | 不移动 | 可用 |

  长按重定位：已放置（未锁定）时，在轴上按住约 300ms（不超出触摸容差范围）即「抓起」游标，给一次轻震动反馈，之后拖动跟随、松手落位；吸附对长按拖动的落点照旧生效。首次放置不受此限（无游标时点按/拖动照旧）。弧段泳道点按（出目标详情窗）与标记热区点按（出详情）不受影响、语义不变。锁定开关：时间条上设「锁定 / 已锁定」切换钮（锁定态以填充 + 文案双通道呈现，不只靠颜色），只在游标态出现；锁定后轴上点按、拖动、长按一律不移动游标，步进仍可用（明确意图动作）；「看整晚 ✕」退出后点轴回到保留位置是恢复而非新放置，锁定不拦。锁定状态与游标同属所选日期之夜，切日期一并复位为未锁定无游标态。
- **与日期切换的关系**：游标属于所选日期的那一夜，切换日期时复位为无游标态（见 7.3）。
- **显示口径（0.5.0 实现，0.5.1 修订，0.5.2 再修订，0.7.0 修订）**：轴上弧段只显示排序后的前 10 个（与整晚短名单的上限一致），其余达标目标不画弧。轴下不显示达标计数行（0.5.2 起删除；0.7.0 起轴下仅余状态行）；目录加载失败时只显示不可用提示，不留计数空行。弧段按目标的 5 分钟采样序列绘制（采样分辨率即弧段端点精度；弧段的收尾开区间终于轴终点而非最后一个采样点）。
- **吸附落点口径**：关键时刻带秒级精度，游标的最小单位是 1 分钟，吸附落点取关键时刻截断到整分的值，气泡时刻名只在游标确实落在（截断后的）关键时刻上时显示；时间条步进不做吸附。时间条长按语义：按下先步进 1′，持续按住超过约 0.45 秒后改为每约 0.16 秒步进 10′，松开即停。
- **气泡回退口径**：游标评估未返回时，气泡的月高与月相照明都由时间轴自身 5 分钟采样在游标时刻插值得到，两者描述同一时刻；评估返回后换为该时刻的历算精确值。光害为地点级数值，不随游标时刻变化。
- **块内文字省略规则**：中天标注仅当其所在分段宽度 ≥ 文字估算宽度 + 10dp 时才绘制，放不下则省略（详情窗始终给出同一组数字）；目标名放不下时省略号截断。文字一律不缩字号、不与相邻分段重叠。
- **全画幅构图建议口径**：按 36.0×24.0mm 画幅计算：长边视场角 = 2·atan(18/f)，占比 = 目标长轴角尺寸 / 长边视场角；建议焦距区间为占比 1/3（短焦端）至 2/3（长焦端），并给出占比 1/2 的参考焦距与占比。边界：目录无角尺寸 → 不给焦距建议，详情窗内明示无尺寸数据；理想焦距整体超出 24–2000mm 常用范围 → 不报范围，改给 2000mm（目标过小）或 24mm（目标过大）处目标占长边的比例；范围部分越界时按界钳制并按钳制后的参考焦距重算占比，所报数字始终自洽。呈现（0.8.2）：详情窗数据网格第 6 行两格给建议焦距区间与参考焦距，占比余量与封顶 / 无尺寸明示为网格下方构图注（见「数据网格」条）。

### 7.6 时区口径

- 手动编辑经纬度后，一切时刻按**所选地点坐标对应的时区**计算与显示（以坐标查时区），不按设备时区。
- 显示时区与设备时区不一致时，沿用既有时间健康检查提示（见第 5 节），并在今晚页以一行小字标注当前显示时区名（如「时刻按 America/New_York 显示」）。
- GPS 重新定位后，按新坐标对应的时区计算与显示。

补充（0.4.0 实现口径）：

- **解析方案**：离线内置一份粗粒度的陆地区域框表（轴对齐经纬度框、按具体程度排序、首个命中框为准），坐标 → 时区解析在领域层以纯函数实现（`SiteTimeZone`）。GPS 定位、手动编辑经纬度、收藏地点三条通道走同一解析路径。
- **解析结果**为 `ZoneId`，夏令时切换由 java.time 按该时区的规则处理，应用层不自算偏移。
- **回退口径**：坐标落在一切框外（海洋、中亚、俄罗斯大部、非洲与南美洲部分地区等）时不解析，回退设备时区；今晚页照常以小字显示实际所用时区名，不把回退结果呈现为坐标解析结果。
- **精度边界**：框表是近似——框界与真实时区边界不重合，边界地区可能落入相邻时区；已知简化包括亚利桑那州（随山地时区框处理、与该州大部不实行夏令时的口径不符）、阿留申群岛（随阿拉斯加框）、纽芬兰（随大西洋加拿大框）、印度东北部与中国框交界一带、伊比利亚西侧（葡萄牙框先于西班牙框命中，加利西亚等地解析为 Europe/Lisbon，与马德里相差 1 小时）。此类误差以「界面明示实际时区名 + 时间健康检查」兜底，不静默呈现假精度。
