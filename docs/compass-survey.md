# 罗盘 / 姿态指向开源选型调研（结论落仓）

调研日期：2026-10-28。范围：目标详情弹出窗实时指向（电子罗盘 + 高度指示）所需的传感器融合、真北修正、精度呈现与指向 UI，评估 GitHub 现成项目能否直接复用。评估纪律沿用 DEVELOPMENT-RULES 第 B 节：任何外部代码只能进 `DeviceOrientationProvider` 适配层或 UI 组件层，domain 不沾；版本与来源须可钉死记录。

**本仓许可证基线：MIT**（仓库根 LICENSE 文件）。相容性以此为准：MIT / Apache-2.0 / BSD 可并入；GPL-2.0 / GPLv3 / AGPL 代码不能并入（并入即须整仓改 GPL 分发），只能读思路。

数据来源说明：star / fork / 许可证 / 提交数均于 2026-10-28 打开各仓库 GitHub 主页实查；个别无法直读的字段在候选条目中注明来源与未核实点。

## 1. 问题结构（决定选型的关键事实）

「手机指向」拆开是五块，其中三块是 Android 平台自带能力，不是库的领地：

| 子问题 | 平台现成件 | 说明 |
|---|---|---|
| 陀螺+加速度+磁力计融合 | `SensorManager` 的 `TYPE_ROTATION_VECTOR` | 厂商传感器中枢已做融合，输出四元数/旋转矩阵；应用层再叠一层自研融合是重复劳动 |
| 磁偏角真北修正 | `android.hardware.GeomagneticField` | 平台内置地磁模型，按经纬度/海拔/日期离线给出磁偏角，精度约 0.5° 内 |
| 精度档与校准状态 | `onAccuracyChanged` / 旋转矢量精度 | HIGH/MEDIUM/LOW/UNRELIABLE 四档由系统上报，App 只负责呈现与提示校准 |
| 低通平滑 | 无现成件 | 圆周量（航向）须在单位圆上平滑，约几十行代码，无独立成库的份量 |
| 罗盘/高度尺 UI | 无现成件可用 | 本仓有自有设计令牌（仪器感、红光主题、双语、对准滞回状态机），任何第三方控件都得重皮肤，等于重写 |

真正需要编写的只有适配层接线（约 200 行量级）+ domain 纯函数 + 自有 UI。库能替代的部分，恰好是最薄的部分。

## 3. 借鉴要点（不引入代码的做法级借鉴）

- **Andromeda `sense` + Trail-Sense**：传感器层在其 andromeda 库的 `sense` 模块。作者发布的 AR 技术文章给出了完整套路：`remapCoordinateSystem` 摆正坐标系 → `GeomagneticField` 取磁偏角并旋转矩阵 → ENU 坐标投影。这正是适配层要做的三步，等于有一份被真实 App 验证过的参考实现可对照。Trail-Sense 7.4.0 更新日志有「靠近金属时上报更低罗盘精度」——精度诚实呈现的产品化做法，与本仓指向区的精度提示口径同向，触发思路可借鉴。不整包引入的理由：① README 明言为作者自用、无文档；② 235 个 Release 的高频变更说明 API 按作者自己的 App 需求演化，钉版本后升级与否都尴尬；③ 只为 `sense` 一个模块引入 JitPack 与同门依赖，换来的代码量与自写适配层相当，而 DEVELOPMENT-RULES B 节的版本钉死与来源记录负担一点不少。MIT 允许把个别类 vendor 进适配层并保留版权头——若将来发现某个具体类明显优于自写，再按 B 节纪律单类摘取。
- **FSensor**：它是「不用系统融合、自己从裸传感器算姿态」的库，五种融合算法 + 三种平滑滤波，参数暴露齐全，有论文实测其互补滤波静态航向标准差在 3° 内。作为融合算法库它是完成品；但本项目的场景里 `TYPE_ROTATION_VECTOR` 已经在传感器中枢做了同样的事，且它不处理磁偏角与精度语义，与本端口要解决的问题不对口。故只留作同端口可换备选：仅当真机验证发现目标设备平台融合明显不佳时，才在同一端口后替换适配器，domain 与 UI 不动（ADR-0004 后果段同此登记）。
- **Stardroid v1**：双输入路径（rotation vector 或加速度+磁力计）与磁偏角策略切换、「校准 ≠ 精度」的呈现经验可读；代码年代与架构摘取成本过高，不摘取。v2 为 GPLv3，不接触。

---

## 4. 结论

不引入任何罗盘 / 融合库，`DeviceOrientationProvider` 适配层自研：平台 `TYPE_ROTATION_VECTOR`（无此传感器时回退加速度计 + 磁力计）+ `GeomagneticField` 磁偏角修正 + `onAccuracyChanged` 精度档，低通平滑与指向 UI 按自有设计令牌实现。借鉴出处与许可证标注落在适配器注释与 ADR-0004：Andromeda `sense`（MIT，Kyle Corry）的真北处理形态，与 Trail-Sense（MIT，同作者）「靠近金属时上报更低罗盘精度」的做法。FSensor 留作同端口可换备选，本批不引入。
