# ADR-0005: 相机取景经 CameraViewfinderPort 端口接入

- 日期：2026-10-31
- 状态：Accepted

## 背景

0.17.0 的地景取景捕获需要一条实时相机预览：用户把画面中心标记对准地景顶、定住写入该瞬间相机光轴仰角。这是本项目第一次引入相机依赖——此前只有定位与方向传感器两类外部能力，分别经端口隔离（ADR-0004）。相机栈的类型面大（提供者、生命周期绑定、用例、表面请求），若 UI 直接调用，分层将被穿透（DEVELOPMENT-RULES A、B 节），且「只预览、不拍照、不存图」这一隐私口径必须落成代码事实而非注释承诺。

选型（调研先行，候选逐一核对维护状态与许可）：官方 CameraX 的 Compose 取景组件 `camera-compose`（CameraXViewfinder）为首选——官方维护、Apache-2.0、只做表面呈现；第三方 CameraView（MIT）维护已放缓且功能面包含本 App 明确不取的拍摄能力；Camposer 只是同一官方栈的封装层，多一层依赖不换收益；Camera2 原生接线的成本与出错面都远高于本用途所需。

## 决定

- **新增 app 层端口 `CameraViewfinderPort`**（`app.camera` 包）：取景面是一个 Compose 视图，端口签名天然带 Compose 类型，故落 app 层而非 domain——domain 不因本批改动（方向样本新增的光轴仰角字段走既有朝向端口，见 ADR-0004 的端口演进）。端口只出自有词汇：呈现一个预览面 + 自有失败枚举（不可用 / 打开失败），无任何相机栈类型。
- **CameraX 类型只许出现在单个适配器文件** `CameraXViewfinderAdapter.kt`：版本四构件对齐官方稳定线 1.6.2（camera-core / camera-camera2 / camera-lifecycle / camera-compose），经端口隔离；上游 API 变化时只改该文件与本 ADR。
- **只绑预览用例**：适配器不构造拍摄与帧分析用例，「不拍照不存图」由源级断言测试钉死（断言适配器全文不出现该两类用例的类型名），作为可回归的代码事实而非口头口径。
- **预览填充为对称中心裁切**：取景组件缺省的 Crop 填充显式传入——只有对称裁切下预览中心才恒为相机光轴的像，取景对准语义立于此上。
- **权限只在点捕获时申请**：CAMERA 权限不随进页 / 进步 / 开开关触发（沿定位权限的既有先例）；Manifest 登记 CAMERA 与 `camera.any`（required=false），拒绝与无相机均经端口失败口径落罗盘捕获兜底。
- **红光形态收适配器内**：红光模式下预览覆红色半透明层、自动曝光补偿经相机控制压到最低，两者都在适配器内完成，UI 只传红光布尔；滤层是乘法压暗加染色、不是主题级深红，限度写入规格。
- **同层备选**：`camera-compose` 若不可用，备选为同栈下层的 `viewfinder-compose`，切换只动适配器一文件，端口与 UI 不动。

## 后果

- APK 体积增加（实测值随 0.17.0 发布记录登记）：相机栈为原生与字节码混合构件，增量以发布实测为准，不预估充数。
- 无相机或权限被拒的设备功能无死路：取景捕获不可用时罗盘捕获与键入照常，端口失败口径保证界面明示而非空白预览。
- 真机验证项新增：取景预览中心与光轴一致性（对称裁切不变量）在目标设备上抽查；曝光补偿最低档在红光下的实际压暗程度需真机调滤层透明度。
- 上游面收敛：CameraX 升级、替换或回退到备选组件，业务代码零改动（合入自检 B 条）。

## 修订（2026-10-31，路线 B：实发版本降至 1.5.1）

上文「决定」条的版本锁定为设计选型口径（对齐官方稳定线 1.6.2）。施工首步实测：CameraX 1.6.2 的构件元数据要求 compileSdk ≥ 36、AGP ≥ 8.9.1，且其类以 Kotlin 2.1 元数据编译——与项目现行工具链（Kotlin 2.0.20、AGP 8.5.2、compileSdk 34）整整差一代，同层备选 viewfinder-compose 1.6.2 门槛相同。经 2026-10-31 裁定（路线 B），实发版本降为同栈的 **CameraX 1.5.1**：`camera-compose` 的 CameraXViewfinder 接口与 1.6.2 相同，适配器与端口代码零改动；工具链只做小升（AGP 8.6.0、compileSdk 35，Kotlin 不动）。本 ADR 的端口隔离、只绑预览、源级断言等决定全部不变；偏离仅此版本号一行，登记于此与 UI 规格 §7.9 沿革、功能设计 §11 补充行。
