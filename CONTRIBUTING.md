# Contributing

Issues and pull requests are welcome — bug reports, feature suggestions for
the exposure models, and especially **data corrections**.

- **Data corrections** (camera read-noise / dual-gain figures, catalogue
  entries, shower or eclipse table values): please cite a measurable,
  checkable source (e.g. PhotonsToPhotos, the upstream catalogue, NASA GSFC)
  in the issue or PR description — values without a source can't be merged.
- **Code / docs PRs**: keep changes small and focused; for anything touching
  the calculation models, include the formula or reference you implemented.
  All code must follow [DEVELOPMENT-RULES.md](DEVELOPMENT-RULES.md)
  (layering, third-party adapter isolation, contract tests) — the pre-merge
  checklist there is part of every PR.
- **Conduct**: be respectful and constructive; disagreements about exposure
  philosophy are settled with measurements, not volume.

贡献说明（中文）：欢迎提 issue 与 PR，尤其是数据纠错——请附可核查的数据来源；涉及计算模型的改动请注明所依据的公式或出处。全部代码须遵守 [开发规则 DEVELOPMENT-RULES.md](DEVELOPMENT-RULES.md)，其合入自检清单是每个 PR 的一部分。
